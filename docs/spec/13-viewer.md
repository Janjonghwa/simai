# 13. 뷰어

Three.js가 유일한 렌더러다. 배경·사람·장비·PPE·구역·경보가 같은 장면과 깊이 버퍼에 있어야 책상 뒤 사람의 가림이 맞기 때문이다. 뷰어는 경보 경로가 아니며, 뷰어가 멈춰도 경보는 계속된다.

## 13.1 장면 구성

| 요소 | 표현 |
|---|---|
| 정적 배경 | 정적 3D glTF(MapAnything 디지털 트윈, 확장 시 Unreal에서 조명을 구운 glTF). 정적 3D 전에는 BEV 평면도 바닥 이미지. 2D 개요 화면은 BEV 평면도(수정 6) |
| 사람 | \[MVP\] Tier 0 골격 구동 기본 메시 아바타. \[EXP-02/확장\] MHR 메시·동적 포즈·관측 기반 외형/텍스처를 점진적으로 개선한 실사형 메시 아바타로 대체 표시 가능(안전 판단의 근거는 변경하지 않음) |
| 장비 | 등록 GLB + 반경 표시(확장) |
| 구역 | 반투명 입체(다각형 + 높이 범위), 유형별 색 |
| 경보 | 대상 아바타 강조 + 이벤트 목록, 같은 사람의 여러 규칙은 한 묶음 |
| 불확실 점유 | UNKNOWN_OCCUPANCY 볼륨을 점선 외곽으로 |

## 13.2 상태 표시 규칙

- 관측 상태: OBSERVED 실선 / PREDICTED 반투명 + 예측 궤적 / UNKNOWN 마지막 위치에 물음표 표식(아바타 제거하지 않음).
- 관절 가시성이 거짓인 관절은 흐리게 처리한다. 아바타는 접지가 확인되면 발을 ground_anchor_xyz에 맞추고, 아니면 pelvis_xyz 기준으로 배치하며 “접지 미확인”을 표시한다(5.2).
- 데이터 연령(staleness)과 System Health를 화면 상단에 항상 표시한다.
- 현재 Scene 버전과 배경 자산 버전이 다르면 경고한다.
- 각 아바타 위에 알림 채널 아이콘(BOUND/UNBOUND/LOST, 확장)을 표시한다.
- 관리자 화면에 “추적 인원 vs 활성 워치 수”를 표시한다(확장).

## 13.3 PPE 표현 (확장)

PPE는 실시간 형상 복원이 아니라 상태 판정 결과에 따라 미리 만든 모델을 붙인다.

| PPEState | 표현 |
|---|---|
| WORN | 안전모(머리 뼈 부착)·조끼(몸통 뼈 스키닝)를 실물처럼 표시 |
| UNKNOWN | 반투명 또는 외곽선만 |
| NOT_WORN | 모델 없음 + 경고 표식(PPE 필수 구역이면 R9) |

크기는 3D 골격의 어깨 폭·몸통 길이·머리 크기로 맞춘다(크기별 모델 중 선택 또는 비율 조정). 선택적으로 crop에서 안전모 색을 뽑아 모델 색을 바꾼다.

## 13.4 화면

- 실시간 관제: 3D 장면, 이벤트 목록, 상태 표시줄
- 구역 편집: 다각형 그리기, 높이·유효 시간·요구 조건 지정
- 레이아웃 편집(②): 개구부·비계·장비 배치, 보고서 생성 요청
- 리플레이(확장 1): 타임 슬라이더, 이벤트 점프
- 시뮬레이션·What-if(확장): PLANNED·WHAT_IF 결과 표시. 실시간 화면과 시각적으로 구분한다.

## 13.5 성능 목표

\[MVP 기본 메시\] 아바타 10명에서 30 FPS 이상, 아바타 발과 바닥 오차 5cm 이하(G5). \[EXP-02 HMR\] 동일 입력에서 별도 추론 지연·메시 갱신 빈도·VRAM·렌더링 FPS를 측정해 적용 가능 여부를 결정하며 기본 G5 목표를 자동 변경하지 않는다.

## 13.6 비상 화면

Three.js 뷰어가 멈췄을 때를 대비해, World 상태만으로 그리는 가벼운 2D 평면 상태 화면을 둔다. 무거운 렌더러 장애가 상황 인식 장애가 되지 않게 하기 위함이다.
