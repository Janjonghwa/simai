# 부록 E. 시연 시나리오

시연에서 보여줄 장면의 순서와 실패 시 대체를 미리 정한다. 장면별 시간·인원은 초기안이며 리허설에서 조정한다. 당일 점검표와 시작 순서는 18.2 를 따른다.

## E.1 원칙

- **라이브 시연 + REPLAY 대체.** 기본은 라이브로 하고, 라이브가 안 되면 같은 장면의 녹화를 REPLAY 출처로 재생한다. REPLAY 출처는 실제 알림 채널로 나가지 않으므로 반장 PWA·노트북 로컬 경보는 울리지 않고 관제 화면 경보만 보인다(2장 원칙 10, 3.10 점검·리허설). 이 차이를 발표에서 미리 말한다.
- **시험 프로파일 표시.** 높이 규칙은 40cm 단상에 맞춰 임계값을 낮춘 시험용 `rule_version`(7.4)으로 시연한다. 화면에 “시험 프로파일(rule_version)”을 표시하고, 40cm 단상과 낮춘 임계값을 쓴다는 사실을 발표에서 설명한다.
- **주장 범위.** 정확도 수치는 개발 교실 실측 결과(15.1)로만 말하고, 시연 현장 수치를 게이트 합격으로 말하지 않는다.

## E.2 장면 순서(초기안)

| 순서 | 장면 | 인원 | 시간 | 보여줄 것 | 실패 시 대체 |
|---|---|---|---|---|---|
| 1 | 시스템 상태 | 0 | 1분 | 카메라 4대 OK·CALIBRATED·NOMINAL, 정적 3D 와 BEV 평면도, 시험 프로파일 표시 | 미리 캡처한 화면 |
| 2 | 위치·추적 | 2 | 2분 | 두 사람 교차·나란히 걷기에서 World ID 유지, 높이 포함 위치 | 같은 장면 REPLAY |
| 3 | 구역 진입(R1) | 1 + 반장 | 3분 | 진입 → 노트북 로컬 경보·관제 화면 경보·PWA 알림 → 반장 ACK 로 소리 정지 → 조치 사진 | REPLAY(화면 경보만) |
| 4 | 단상 고소·가장자리(R2·R3) | 1 | 2분 | 등록 작업면(40cm 단상) 위 접지, 가장자리 근접 경보 | REPLAY(화면 경보만) |
| 5 | 장애 대응 | 1 | 2분 | 카메라 1대 가리기 → 구역 감시 저하(R7), 구역 안 관측 상실 시 자동 해소 안 함(R6) | REPLAY |
| 6 | VLM 근거·TBM 보고서 | 0 | 2분 | CRITICAL 이벤트의 VLM 근거, 가상 레이아웃 TBM 보고서(인용 조항) | 미리 생성한 결과 |
| 7 | 최소 리플레이 | 0 | 1분 | 시각 슬라이더로 방금 장면 재생 | — |

## E.3 설치 시간 예산

시연 현장 설치는 아래 순서로 하고, 단계별 소요 시간은 리허설에서 재서 채운다(확인 필요).

| 단계 | 내용 | 소요 시간 |
|---|---|---|
| 1 | 카메라 거치·네트워크 확인(3.4, 3.5) | 리허설 실측 |
| 2 | 실측 정물 배치 → 걷기 보정 → CALIBRATED(4.3, 4.4) | 리허설 실측 |
| 3 | 정물 스케일 확인 | 리허설 실측 |
| 4 | MapAnything 정적 3D → Scene 커밋(5.3) | 리허설 실측 |
| 5 | 구역·작업면 등록 → 구성 묶음 “현장 적용됨”(7.5) | 리허설 실측 |
| 6 | 시험음·시험 푸시(3.10) | 리허설 실측 |

## E.4 리허설 항목

- 시연과 같은 사이트·GPU 등급·저장 위치로 한다(3.12). TensorRT 엔진 캐시와 GPU 인스턴스 기동 시간(시작 절차 포함)을 확인한다.
- 시연장 망(SSAFY 망)에서 기본 경로인 EC2(`simai.live:22`) SSH 경유 + Pod 공개 포트 Direct TCP(EC2 보안 그룹 인바운드 22 허용 확인 포함)를 10분 이상 연속 시험하고, LTE 테더링 업링크(두 번째 업링크)와 RunPod HTTPS 프록시(443 + wstunnel, 최후 예비)로 전환해 본다(3.12, 18.1). 리허설·시연 중에는 EC2 CPU 를 같이 쓰는 CI 빌드를 피한다.
- 엔드포인트 등록 → 노트북 접속, 노트북 재접속 후 현장 경보 재동기화(3.10)를 확인한다.
- 노트북 OS 설정(업데이트 중지, 집중 모드, 출력 오디오 장치 고정, 서비스 자동 기동)을 확인한다(18.1).
- 위험 이벤트를 만드는 장면 연습은 녹화한 뒤 REPLAY 로 돌리고(연결 점검·보정 촬영은 LIVE 연결 + 시험 알림 경로, 3.10 점검·리허설), 장면 2\~5 의 REPLAY 대체 녹화를 미리 만들어 REPLAY 재생에서 실제 알림이 나가지 않는지 확인한다.
- T-60분 go/no-go 점검표(18.2)를 그대로 한 번 돌린다.
