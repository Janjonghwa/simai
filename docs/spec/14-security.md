# 14. 보안

외부로 열리는 모든 지점에 인증을 걸고, 모든 외부 통신을 TLS로 암호화한다. 특히 RunPod 포트는 공개 IP로 열리므로 인증 없이 두지 않는다.

| 대상 | 정책 |
|---|---|
| EC2 공개 주소 | HTTPS 인증서, 필요한 포트만 개방, 관리 포트는 IP 제한 |
| 뷰어·PWA | 계정 로그인, 역할 3종(관리자, 반장, 열람). 구역·규칙·레이아웃 수정은 관리자만 |
| 노트북 게이트웨이 | 기기 토큰, WebSocket over TLS(wss) |
| 워치 | 기기별 토큰, wss. 가짜 ACK로 경보를 확인된 것처럼 만드는 것을 막는다 |
| RunPod | API 키 + EC2·노트북 IP만 허용, 콜백은 HMAC 서명 검증. 영상 수신은 RunPod Direct TCP 포트 하나에서 Tier 0 서비스가 TLS를 직접 종료하고 노트북 기기 토큰으로 인증(12.7) |
| 카메라 RTSP 계정 | 카메라별 별도 계정, 교실망 안에서만 접근 |
| 비밀 값 | API 키·토큰·계정은 저장소에 넣지 않고 환경 변수·비밀 저장소로 관리 |
| 객체 저장소 | 비공개, 임시 서명 주소로만 업로드·조회 |
| 개인 정보 | 워치 등록자 이름 테이블은 관리자만 조회, 조회 기록 남김 |
| Unreal MCP(확장) | 에디터 루프백만 허용, 빌드 워커 툴 범위 제한 |
