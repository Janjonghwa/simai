# 9. 문제-기능-모듈-게이트 추적표

1.1의 네 가지 문제는 모두 MVP 기능으로 직접 다뤄지고, 각 기능은 측정 게이트로 검증된다.

| 문제 | 기능 | 사용 모듈 | 검증 게이트 |
|---|---|---|---|
| 좌표 부정합 | ⑤ 3D 위치 추적 | Tier 0, 삼각측량, 자동 보정, World 좌표계 | G0, G1, G2 |
| 떨어짐 | ⑥ 입체 구역 + R2·R3·R4 | 3D 골격 Z, 정적 3D 가장자리, Risk Engine | G2, G4, G5, G6 |
| 떨어짐 (사전) | ② TBM 보고서 | Risk Engine(계획 모드), VLM 보고서, RAG | G6, G7 |
| 알람 피로 | ⑥ + VLM 근거, 히스테리시스, 병합 | Risk Engine, VLM | G6, G7 |
| 인지-조치 간극 | ⑨ 반장 PWA, 조치 상태 | 알림 라우팅, PWA | G8 |
| 정적 장면 복원·정합 | EXP-01 / ⑤·M3 정적 3D | MapAnything Native·glTF·Scene 버전 | G1, G4, EXP-01 리뷰 |
| 움직이는 실사형 메시 아바타 | EXP-02 / 확장 인체 메시 | Fast SAM 3D Body, MHR, World ID 정렬, 외형 갱신 | EXP-02, INT-01 및 G5 영향 검증 |
| 사후 대응 중심 | ⑩ 기록 → 리플레이 | Spatial DB, 버전 관리 | G3, 리플레이 검증 |
| 장비 협착 | R8, ① 동선 시뮬레이션 | 장비 형상·방향, Risk Engine(계획 모드) | 확장 게이트 |
| 개인 경고 부재 | 워치 알림 | 움직임 대조 연결, 워치 앱 | 확장 게이트(워치) |
| 보호구 미착용 | R9, PPE 표현 | PPE 워커, 뷰어 | 확장 게이트(PPE) |
| 감시 사각 | ④ 배치 추천 | 3D 가시성 엔진 | 확장 게이트 |

모든 기능이 같은 World 좌표, Risk Engine, Spatial DB를 공유하므로, 사후 분석 결과(⑩·③)가 다음 날 사전 예방(②·①·④)으로 돌아가는 루프가 생긴다.
