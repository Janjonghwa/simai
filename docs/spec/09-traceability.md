# 9. 문제-기능-게이트 추적 요약

1.1의 문제 중 좌표 부정합·떨어짐·사후 대응 중심은 MVP 기능으로 다루고, 장비 협착(R8)은 확장(부록 C)이다. 이 장은 문제 → 기능 → 게이트의 요약만 둔다. 기능별 세부 추적(요구사항 ID → 게이트)은 요구사항 명세서(`docs/requirements.md`)의 비고 열이 정본이다.

| 문제 | 기능 | 검증 게이트 |
|---|---|---|
| 좌표 부정합 | F-05 3D 위치 추적, 자동 보정 | G0, G1, G2 |
| 떨어짐 | F-06 입체 구역 + R2·R3(등록 작업면 OBB 가장자리)·R4 | G2, G5, G6 |
| 떨어짐 (사전) | F-02 TBM 보고서 | G6, G7 |
| 알람 피로 | 발생 지속 조건·히스테리시스·병합·재개, VLM 근거 첨부 | G6, G7 |
| 인지-조치 간극 | F-09 반장 PWA, 조치 상태 | G8 |
| 정적 장면 복원·정합 | EXP-01 / M3 정적 3D | G1, G4, EXP-01 리뷰 |
| 움직이는 실사형 메시 아바타 | EXP-02 / 시연 범위 인체 메시·외형(5.6, 20.3) | EXP-02(E-GATE-0~3), INT-01, G5 영향 검증 |
| 사후 대응 중심 | F-10 기록 → 최소 리플레이 | G3, 부록 D |
| 장비 협착 | R8, F-01 동선 시뮬레이션(부록 C) | 게이트 미정 |
| 개인 경고 부재 | 워치 알림(부록 C) | 부록 C 워치 게이트 |
| 보호구 미착용 | R9, PPE(부록 C) | 부록 C PPE 게이트 |
| 감시 사각 | F-04 배치 추천(부록 C) | 게이트 미정 |

모든 기능이 같은 World 좌표, Risk Engine, Spatial DB를 공유하므로, 사후 분석 결과(F-10·F-03)가 다음 날 사전 예방(F-02·F-01·F-04)으로 돌아가는 루프가 생긴다.
