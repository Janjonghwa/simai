## 19.2 로드맵

**기존 장비 도착 전 준비 작업:** 장비 사양 확정·교실 실측·평면도, 시뮬레이터(가상 교실·사람·C110 사양 가상 카메라), Risk Engine과 단위 테스트, 공개 다시점 데이터셋(WILDTRACK, CMU Panoptic)으로 사전 검증, 백엔드·뷰어·PWA 골격, VLM RAG 준비, 동의서·촬영 목록.

**2026-10-16 GPU 확보 이후 선행 실험:** EXP-01 정적 장면과 EXP-02 HMR을 각각 하나의 대형 Feature 티켓으로 병렬 준비한다. 중량 GPU Run은 큐에서 직렬로 실행하고, 결과 비교와 독립 재현 검증을 거쳐 INT-01 최소 공간+메시 통합 데모를 만든다. 기존 M1→M3 및 G0→G8 제품 게이트 순서는 그대로 유지한다.

**MVP 순서:**

1. G0 기반 → G1 자동 보정 → G2 위치·추적 → G3 실패 대응
2. G4 정적 3D → G5 3D 골격·뷰어
3. G6 위험 규칙 → G7 VLM·보고서 → G8 PWA

기능 통합은 1.3의 M1 → M2 → M3 순서로 한다.

**확장 순서:**

1. ⑩ 리플레이 화면(로그가 이미 있어 비용 대비 효과가 가장 큼)
2. ① 위험 동선 시뮬레이션
3. ⑧ 에이전틱 리포팅
4. ③ What-if · ④ 배치 추천
5. ⑦ 공정 연계

**3D 고도화 트랙(2026-10-16 GPU 확보로 선행 착수):** EXP-01 정적 배경(MapAnything Native), EXP-02 인체 메시(Fast SAM 3D Body/MHR), INT-01 동일 월드 통합을 큰 Experiment 단위로 먼저 검증한다. PPE 워커·워치·정적 공간 온라인 갱신·Unreal 배경 빌드는 기존 확장 분류를 유지한다. 해당 Experiment가 성공했다고 곧바로 MVP 요구사항으로 확정하지 않는다. EXP-01은 M3 정적 3D(G4)의 선행 검증이며 별도 작업이 아니다.
