## 19.2 로드맵

**준비 작업(진행 현황은 Jira):** 개발 교실 게이트용 실측 지점 정하기, 시뮬레이터(가상 교실·사람·C110 사양 가상 카메라), Risk Engine과 단위 테스트, 공개 다시점 데이터셋(WILDTRACK, CMU Panoptic)으로 사전 검증, 백엔드·뷰어 골격, RAG 문서 준비, 동의서·촬영 목록.

**2026-10-16 GPU 확보 이후 선행 실험:** EXP-01 정적 장면과 EXP-02 HMR을 각각 하나의 대형 Feature 티켓으로 병렬 준비한다. 중량 GPU Run은 큐에서 직렬로 실행하고, 결과 비교와 독립 재현 검증을 거쳐 INT-01 최소 공간+메시 통합 데모를 만든다. M1→M3 및 G0→G9 제품 게이트 순서는 그대로 유지한다.

**MVP 순서:**

1. M1: G0 기반 → G1 자동 보정 → G2 위치·추적 → G3 실패 대응, G6-R1·R6·R7
2. M2: G5 3D 골격·뷰어, G6-R2·R3·R5, G8 원격 전달(관제 화면)
3. M3: G4 정적 3D → G7 VLM·보고서, 최소 리플레이, G9 PPE·G6-R9, 부록 D 전체 회귀

기능 통합 범위는 1.3의 M1 → M2 → M3 표를 따른다.

**확장 순서:** 부록 C 를 따른다.

**3D 고도화 트랙(2026-10-16 GPU 확보로 선행 착수):** EXP-01 정적 배경(MapAnything Native), EXP-02 인체 메시(Fast SAM 3D Body/MHR), INT-01 동일 월드 통합을 큰 Experiment 단위로 검증한다. PPE 워커는 M3(5.5, G9)이고, 신호수 표식·워치·정적 공간 온라인 갱신·Unreal 배경 빌드는 확장(부록 C)이다.
