정확도 게이트의 절대 오차 항목(G1 카메라 높이, G2 실측 격자, G4 실측 대비)은 개발 교실에서 한 번 줄자·레이저로 재서 판정한다. 시연 현장은 실측 없이 운영하며 현장 수치를 게이트 합격으로 주장하지 않는다(수정 6).

G5의 “한 카메라 제외 재투영”은 3대로 삼각측량한 관절을 4번째 카메라에 투영해 그 카메라의 실제 keypoint와 비교하는 방식으로, 모션캡처 장비 없이 관측 일관성을 잰다. 실제 3D 위치의 정답은 아니므로, 위치 정확도는 G2의 실측 XYZ로 따로 판정한다. G6는 규칙별로 판정한다(G6-R1 등). G6-R6·R7은 G3의 해당 항목과 같은 측정으로 판정한다.

## 15.3 시나리오 데이터셋

4대 동기화 녹화를 한 번에 촬영해 모든 게이트 비교에 재사용한다.

- 시간 동기화: 네 카메라가 함께 보는 위치의 ms 시계 휴대폰·깜빡이는 LED
- 보정: 한 명이 교실 전체를 1\~2분 걷기
- 위치 정답: 1m 격자 기반 20곳 이상(중앙, 가장자리, 책상 뒤, 카메라 근처)에 지점당 3회 서기, 키를 아는 사람
- 추적: 두 사람 교차, 나란히 걷기, 서서 작업, 책상 뒤 이동
- 실패: 카메라 1대 가리기·전원 차단, 노트북 네트워크 차단
- 위험: 테이프 구역 진입·경계 머물기, 40cm 단상(고소·가장자리), 매트 위 눕기(낙상), 빠르게 앉기·물건 줍기(오경보용)
- 장비 대체: 카트 이동(확장)
- PPE(확장): 착용·벗기·손에 들기·의자에 걸기·머리 가림
- 워치(확장): 착용자·미착용자 혼합, 공유기 경계 넘기

**준비물:** 줄자, 레이저 거리계, 바닥 테이프, 40cm 단상, 매트, ms 시계 휴대폰.

## 15.4 모델 학습과 비교 실험

학습 전에 기본 성능과 ID 오류가 나는 조건을 먼저 잰다. 학습 순서는 YOLO26x-pose 미세조정(A0 교실 결과가 부족할 때만) → (필요 시) ReID → YOLO26 PPE 검출 → (추적 한계가 확인될 때만) BEV 기반 추적이다. 모두 사전학습 가중치에서 시작하며 처음부터 학습하지 않는다.

**데이터.** 4대 카메라 영상에서 조건이 다른 프레임 500\~1,500장을 초기 가안으로 주석화한다. 필요 수량이 아니라 시작 규모이며, 장수보다 상황 다양성(걷기, 앉기, 물건 줍기, 교차, 책상 뒤 이동, 비슷한 옷, 조명·거리 차이)이 중요하다.

- 관절마다 VISIBLE / OCCLUDED / UNLABELED를 구분하고, 보이지 않는 발 위치를 임의로 찍지 않는다.
- 학습·검증·시험은 프레임 무작위가 아니라 촬영 세션·날짜·가구 배치·참가자 단위로 나누고, 일부 조건은 최종 평가 전용으로 남긴다.
- 주석 부담은 무거운 포즈 모델(ViTPose, Sapiens)로 자동 주석을 만든 뒤 사람이 고치는 방식으로 줄인다.
- COCO 17관절을 유지하면 미세조정으로도 발 관절은 생기지 않는다. 접지는 ContactEstimator(5.2)가 맡는다.
- 공개 다시점 데이터(CMU Panoptic 등)는 보조로만 쓰고 현장 데이터와 분리해 평가한다.

**비교 실험.**

| 실험 | 구성 | 확인할 것 |
|---|---|---|
| A0 기준선 | YOLO26x-pose + 카메라별 TrackTrack + 기하 융합(수정 7) | 현재 성능 |
| A1 관절 개선 | 미세조정 YOLO26x-pose + 같은 추적 | 2D 관절·World XYZ 정확도 |
| A2 ID 개선 | A1 + 선택적 ReID·궤적 매칭 | ID 전환, IDF1, HOTA |
| A3 연구 고도화 | TrackTacular 또는 MVTrajecter | 가림·교차에서 추가 개선 |

포즈 효과는 관절별 정확도·미검출률·G2 World XYZ 오차로, 추적 효과는 IDF1·HOTA·ID 전환·분열·오병합으로 판단한다. 모든 구성에서 4대 합산 처리량과 capture_to_risk 지연을 함께 본다. 채택 순서는 2D 관절 정확도 → G2 World XYZ 정확도 → IDF1·HOTA → 4대 지연이며, G2 World XYZ가 개선되지 않으면 2D 점수만 올랐다는 이유로 새 모델을 채택하지 않는다. 지연은 6.6 목표 안이어야 한다.
