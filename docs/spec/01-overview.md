# 1. 개요와 범위

simai는 고정 카메라 4대로 작업 공간의 사람·장비·정적 구조를 하나의 미터 좌표 3D 디지털 트윈에 올리고, 위험을 근거와 함께 판정해 현장 담당자에게 전달하는 예방형 안전 관제 플랫폼이다.

## 1.1 해결하려는 문제

근거는 국토안전관리원 2025년 건설사고 분석 보고서(CSI)와 국토교통부 스마트건설기술 현장 적용 가이드라인(2021.3)이다.

| 문제 | 내용 |
|---|---|
| 떨어짐 | 사망사고의 52.3%(보고서 33p). 기존 Vision AI는 높이와 맥락을 읽지 못한다 |
| 장비 협착 | 깔림·끼임이 잦고(보고서 19p), 오탐에 따른 알람 피로로 경보가 꺼진다 |
| 사후 대응 중심 | 작업 전 동선 충돌은 짐작에 의존하고, 사고 후에는 파편 영상으로 수기 보고서를 쓴다 |
| 좌표 부정합 | 카메라 픽셀과 도면 좌표가 맞지 않아 “개구부까지 몇 m”를 계산할 수 없다 |

가이드라인은 스마트 안전기술이 설치가 아니라 실제 안전성 제고를 목적으로 하고(1.3조), 성능을 가급적 정량적으로 제시하도록 요구한다(2.2조, 표 4). simai는 모든 판단에 근거와 측정된 정확도를 붙이는 것으로 이에 답한다.

## 1.2 목표

1. 카메라 4대가 한 사람을 하나의 World ID와 미터 좌표(높이 포함)로 안정적으로 관리한다.
2. 정적 공간과 사람의 3D 상태를 갱신한다. 기본·폴백 사람 표현은 Tier 0 골격으로 움직이는 캡슐 아바타이고, 시연 범위(EXP-02, 5.6·20.3·20.6)에서는 MHR 리깅 메시·포즈 스트림(1단계, 상·하의 대표색)과 관측 픽셀 UV 텍스처 누적(2단계, 3DGS 미사용)으로 실제 외형을 반영하는 시각 아바타를 보여준다. 어느 쪽도 실시간 위험 판단을 방해하지 않는다.
3. 카메라·모델·캘리브레이션이 실패하거나 공간이 바뀌어도, 시스템은 모르는 것을 안다고 판단하지 않는다.
4. 위험 판정에서 현장 전달, 조치 확인, 사후 리플레이까지 루프를 닫는다.

## 1.3 범위

**기능 번호.** 기능은 F-01\~F-10 으로 부른다. 요구사항 명세서의 FR ID 와 다르며, 기능 묶음을 가리킨다.

| 번호 | 기능 | 범위 |
|---|---|---|
| F-01 | 위험 동선 시뮬레이션 | 확장(부록 C) |
| F-02 | TBM 리스크 보고서 | MVP |
| F-03 | What-if | 확장(부록 C) |
| F-04 | 배치 추천 | 확장(부록 C) |
| F-05 | 3D 위치 추적 | MVP |
| F-06 | 입체 Geo-fencing | MVP |
| F-07 | 공정 연계 | 확장(부록 C) |
| F-08 | 에이전틱 리포팅 | 확장(부록 C) |
| F-09 | 반장 PWA | MVP |
| F-10 | 기록·리플레이 | 기록과 최소 리플레이는 MVP, 리플레이 확장은 부록 C |

**MVP.** 모든 기능은 3D 디지털 트윈 위에 쌓는다.

| 기능 | 내용 |
|---|---|
| F-05 3D 위치 추적 | 다시점 삼각측량으로 사람의 XYZ와 3D 골격 |
| F-06 입체 Geo-fencing | 다각형 + 높이 범위 구역. 판정은 Risk Engine, VLM 근거는 첨부만 |
| F-09 반장 PWA | 위험 알림, 조치 사진 업로드, 조치 상태 |
| F-02 TBM 리스크 보고서 | 가상 레이아웃에 위험 규칙 적용 + RAG·LLM 보고서 |
| F-10 기록·최소 리플레이 | Spatial DB 저장, 시각 슬라이더로 world_track_state·risk_event 재생 |

**MVP 통합 단계.** 기능을 줄이지 않고 통합 순서를 나눈다.

| 단계 | 통합 범위 | 완료 조건 |
|---|---|---|
| M1 | 4카메라 World 추적, 실측 검증점 위치 확인, R1 구역, R6·R7, 노트북 로컬 경보·관제 화면 경보, 반장 PWA 알림·확인, 기록 | G0\~G3 + G6-R1·R6·R7 |
| M2 | 3D 관절 유효성 게이트, R2·R3 높이 규칙(등록 작업면), R4 낙상 의심(선택), R5 진입 예측, 반장 PWA 조치 상태·사진(불일치 표시는 취소, S15P31A101-411) | G5 + G6-R2·R3·R5 + G8 (G6-R4는 선택) |
| M3 | 정적 3D, VLM 근거, TBM 보고서, 최소 리플레이 | G4 + G7 + 부록 D 전체 회귀 |

**확장 트랙.** 리플레이 확장(Scene 버전 처리 등), F-01 동선 시뮬레이션, F-08 에이전틱 리포팅, F-03 What-if·F-04 배치 추천, F-07 공정 연계, PPE 판정, 워치 알림, 정적 공간 온라인 갱신·임시 형상, Unreal 배경 빌드. 요약은 부록 C 에 있다(인체 메시·외형 아바타 EXP-02 는 시연 범위로 5.6·20.3·20.6 을 본다).

**검증 환경.** 10×10m 교실 테스트베드, Tapo C110 4대, 천장 약 3m, 동시 인원 최대 10명(용량·FPS 목표의 전제).

## 1.4 비목표

- 인증된 안전 장치나 법적 작업중지 판단 주체가 아니다. 사람의 판단을 돕는 보조 시스템이다.
- 개인을 실명으로 식별하지 않는다. World ID는 세션 단위 익명 번호다.
- AI(VLM·LLM 포함)는 경보를 낮추거나 끄지 않는다. 경보 해소는 관측 근거로만 한다.
- 생성형 얼굴 복원·표정 추정·실명 식별은 하지 않는다(외형 텍스처에는 관측된 얼굴 픽셀만 허용하고, 전신 임베딩 재식별은 10/30 이후 G2 측정 뒤 기하 게이트 뒤 보조 비용으로만 검토, 11.5·19.1). 관측 기반 **메시** 아바타(EXP-02)는 시연 범위(1단계 MHR 리깅 메시 + 포즈 스트림, 2단계 관측 픽셀 UV 텍스처 누적, 3DGS 미사용, 5.6·20.3)로 두며, 단계별 품질·성능·Tier 0 독립과 캡슐 폴백은 E-GATE-0\~3 으로 검증한다(20.6).
- 교실 테스트베드 밖의 실제 건설 현장 성능을 주장하지 않는다.
