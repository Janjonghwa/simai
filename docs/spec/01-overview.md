# 1. 개요와 범위

simai는 고정 카메라 4대로 작업 공간의 사람·장비·정적 구조를 하나의 미터 좌표 3D 디지털 트윈에 올리고, 위험을 근거와 함께 판정해 현장 담당자에게 전달하는 예방형 안전 관제 플랫폼이다.

**문서 관계.** 이 문서는 simai Pipeline v1.0\~v1.3(Architecture & Reliability Specification 포함)을 대체한다. 이후 “v1.x”는 이 문서 계열만을 가리키고, 이전 문서들은 “구 Pipeline 문서”로 부른다.

**기준선과 개정 관리.** v1.2 r3 Errata 3을 직전 개발 기준선으로 보존한다. 이번 r4는 사용자가 승인한 GPU 확보·대형 Experiment 방식·인체 표현 목표 변경을 문서화하는 기능 범위 개정이다. 기존 G0\~G8 수치는 검증 전 초기 목표로 유지하며, 변경하려면 실측·결정 기록과 함께 명시적으로 개정한다. 단순 오류 정정은 Errata로 남긴다.

## 1.1 해결하려는 문제

근거는 국토안전관리원 2025년 건설사고 분석 보고서(CSI)와 국토교통부 스마트건설기술 현장 적용 가이드라인(2021.3)이다.

| 문제 | 내용 |
|---|---|
| 떨어짐 | 사망사고의 52.3%(보고서 33p). 기존 Vision AI는 높이와 맥락을 읽지 못한다 |
| 장비 협착 | 깔림·끼임이 잦고(보고서 19p), 오탐에 따른 알람 피로로 경보가 꺼진다 |
| 사후 대응 중심 | 작업 전 동선 충돌은 짐작에 의존하고, 사고 후에는 파편 영상으로 수기 보고서를 쓴다 |
| 좌표 부정합 | 카메라 픽셀과 도면 좌표가 맞지 않아 “개구부까지 몇 m”를 계산할 수 없다 |

가이드라인은 스마트 안전기술이 설치가 아니라 실제 안전성 제고를 목적으로 하고(1.3조), 성능을 가급적 정량적으로 제시하도록 요구한다(2.2조, 표 4). simai는 모든 판단에 근거와 측정된 정확도를 붙이는 것으로 이에 답한다.

## 1.2 목표

1. 카메라 4대가 한 사람을 하나의 World ID와 미터 좌표(높이 포함)로 안정적으로 관리한다.
2. 정적 공간과 사람의 3D 상태를 갱신한다. 사람은 MHR 메시·자세에서 시작해 관측이 누적될수록 실제 외형을 반영하는 시각 아바타를 지향하되, 실시간 위험 판단을 방해하지 않는다.
3. 카메라·모델·캘리브레이션이 실패하거나 공간이 바뀌어도, 시스템은 모르는 것을 안다고 판단하지 않는다.
4. 위험 판정에서 현장 전달, 조치 확인, 사후 리플레이까지 루프를 닫는다.

## 1.3 범위

**MVP.** 모든 기능은 3D 디지털 트윈 위에 쌓는다.

| 기능 | 내용 |
|---|---|
| ⑤ 3D 위치 추적 | 다시점 삼각측량으로 사람의 XYZ와 3D 골격 |
| ⑥ 입체 Geo-fencing | 다각형 + 높이 범위 구역, VLM 근거 판정 |
| ⑨ 반장 PWA | 위험 알림, 조치 사진 업로드, 조치 상태 |
| ② TBM 리스크 보고서 | 가상 레이아웃에 위험 규칙 적용 + VLM 보고서 |
| ⑩ 기록 | Spatial DB 저장(리플레이 화면은 확장) |

**MVP 통합 단계.** 기능을 줄이지 않고 통합 순서를 나눈다.

| 단계 | 통합 범위 | 완료 조건 |
|---|---|---|
| M1 | 4카메라 World 추적, 실측 검증점 위치 확인, R1 구역, R6·R7, 로컬·관제 화면 경보, 기록 | G0\~G3 + G6-R1·R6·R7 |
| M2 | 3D 관절 유효성 게이트, R2·R3 높이 규칙, R4 낙상 의심, R5 진입 예측 | G5 + G6-R2·R3·R5 (G6-R4는 선택) |
| M3 | 정적 3D, VLM 근거·TBM 보고서, 반장 PWA | G4 + G7 + G8 + 전체 통합 회귀 검증 |

**확장 트랙.** MVP와 같은 깊이로 명세한다: ⑩ 리플레이 화면, ① 위험 동선 시뮬레이션, ⑧ 에이전틱 리포팅, ③ What-if·④ 배치 추천, ⑦ 공정 연계, PPE 판정, 워치 알림, SAM 3D Body 강화, 정적 공간 온라인 갱신, Unreal 배경 빌드.

**검증 환경.** 10×10m 교실 테스트베드, Tapo C110 4대, 천장 약 3m, 동시 인원 최대 10명(용량·FPS 목표의 전제).

## 1.4 비목표

- 인증된 안전 장치나 법적 작업중지 판단 주체가 아니다. 사람의 판단을 돕는 보조 시스템이다.
- 개인을 실명으로 식별하지 않는다. World ID는 세션 단위 익명 번호다.
- AI(VLM 포함)는 경보를 낮추거나 끄지 않는다. 경보 해소는 관측 근거로만 한다.
- 얼굴 신원 복원·표정 추정·실명 재식별은 하지 않는다. 단, 기존의 '사실적 외형 아바타 비목표'는 이번 개정으로 변경한다. 관측 기반 실사형 **메시** 아바타는 EXP-02에서 연구하고, 제품·시연 채택 여부는 성능·개인정보·시각 품질 검증 뒤 결정한다.
- 교실 테스트베드 밖의 실제 건설 현장 성능을 주장하지 않는다.
