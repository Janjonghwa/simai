# 4. 좌표·단위 규약과 캘리브레이션

World 좌표계는 첫 CALIBRATED 때 교실의 바닥·벽으로 한 번 정하고 바꾸지 않는다. 캘리브레이션은 마커·실측 평면도 없이 사람의 움직임으로 자동 수행하며, 결과는 버전으로 확정한다. 실측 평면도는 쓰지 않는다(수정 6).

## 4.1 World 좌표계

- 단위: 미터. 오른손 좌표계, +Z 상방
- 원점: 첫 CALIBRATED 때 정한 교실 한 모서리의 바닥
- 축: X·Y는 원점에서 만나는 두 벽 방향(정적 3D·벽 소실점으로 추정), 바닥 Z = 0(사람 발 접지점으로 맞춘 바닥 평면)
- 위험 구역·장비·가상 레이아웃은 모두 이 좌표로 저장한다. 카메라 보정이 바뀌어도 영향을 받지 않는다.
- 좌표계를 정한 뒤 다시 정하면 “좌표계 이전”을 명시적 사건으로 기록하고 모든 데이터를 변환한다.

**BEV 평면도(보조 화면).** 전체 상황을 한눈에 보는 간략한 위에서 본 화면이다. 보정이 끝나면 카메라 4대의 바닥 영역과 정적 3D 를 위에서 본 화면으로 펴서 자동으로 만든다. 좌표·스케일의 기준이 아니고 정확도 목표도 없다. 안전 판단에는 쓰지 않으며, 구역을 그리거나 사람 위치를 2D 로 보여주는 데 쓴다. 메인 공간 표현은 MapAnything 정적 3D 디지털 트윈(5.3)이다(수정 6).

## 4.2 경계별 변환 규칙

변환은 각 경계의 어댑터 한 곳에서만 수행한다. 다른 코드는 World 좌표만 다룬다.

| 대상 | 규약 | World (x, y, z) 로부터 |
|---|---|---|
| 카메라 좌표 | OpenCV: x 오른쪽, y 아래, z 앞 | 외부 파라미터 R, t |
| Three.js · glTF | 미터, 오른손, +Y 상방 | (x, z, −y) |
| Unreal | 센티미터, 왼손, +Z 상방 | (100x, −100y, 100z) |
| 시각 | UTC, int64 밀리초 | — |
| 각도 | 내부 라디안, 화면 표시만 도 | — |

각 어댑터에는 격자점 몇 개를 왕복 변환해 원래 값으로 돌아오는지 확인하는 단위 테스트를 둔다.

## 4.3 자동 캘리브레이션

설치 후 사람이 할 일은 걷기와 한 번의 검증(4.4)뿐이다. 초기 보정은 교실에 한 명만 있는 상태에서 1\~2분 걷기로 시작하되, 부족하면 여러 명이 5분 이상 골고루 걷는다(AutoMagicCalib 권장 조건 참고). 필요한 시간은 G1에서 확정한다.

1. **초기 추정:** 4대 영상을 MapAnything에 넣어 내부 파라미터, 상대 자세, 바닥 평면, 중력 방향을 추정한다. 동일 하드웨어라 한 대의 내부 파라미터를 나머지의 초기값으로 쓰되 최종값은 카메라별로 다듬는다.
2. **좌표계 고정:** 사람 발 접지점으로 바닥 평면(Z = 0)과 중력 방향을, 복원한 벽 형상·벽 소실점으로 축을, 방 모서리 하나로 원점을 정해 고정한다. 스케일은 아래 우선순위로 정한다.
3. **정밀화:** 걷는 사람의 2D keypoint로 번들 조정(HumanCalib 기반, NVIDIA AutoMagicCalib를 G1 비교 후보로)을 수행한다. 바닥 평면은 발 접지점으로 재확인하고, 렌즈 왜곡 계수도 함께 다듬는다.
4. **검산:** 카메라별 독립 높이 추정(CCVS 방식: 머리·발 점으로 초점거리·기울기·높이 맞춤)과 비교한다. 차이가 크면 PROVISIONAL을 유지한다.
5. **동결:** CALIBRATED가 되면 보정을 동결하고 이후에는 감시만 한다.

**스케일 근거 우선순위.** 실측 정물 \> 키를 아는 사람 \> 사람 키 통계(여러 사람이 지날수록 수렴) \> 표준 사물 크기(문, 책상) \> 모델 자체 추정(MapAnything 메트릭). 둘 이상을 교차 확인한다(수정 6).
- **실측 정물:** 시연에 쓰는 안전 장비 중 단단하고 큰 것(안전봉, 라바콘, 바리케이드 등)의 치수를 미리 재서 정물 목록(이름·치수·측정일)으로 둔다. 설치 때 2\~3개를 방의 서로 다른 곳, 카메라 2대 이상에 보이는 위치에 세운다. 시스템이 다시점 삼각측량·정적 3D 에서 정물을 찾아(YOLOE 등) 크기를 재고 목록 치수와 맞춰 스케일을 정한다. 클수록, 서로 멀수록 정확하다(예상 약 1%, 미검증). 안전모는 작아서 보조로만 쓰고, 안전조끼처럼 형태가 변하는 것은 쓰지 않는다.
- **키를 아는 사람:** 보정 걷기를 키를 미리 잰 팀원이 해서 정물과 교차 확인한다(예상 1\~2%).
- 실측 정물이 없으면 스케일 정확도는 2\~5%에 머문다는 것을 보정 버전에 기록한다. 사용한 근거를 보정 버전에 기록한다.

**번들 조정 게이지 고정.** 재최적화마다 전체 장면이 회전·이동·축척되는 것을 막기 위해 바닥 Z = 0, 벽 방향 = 확정한 World 축, 스케일 = 확정한 스케일을 제약으로 건다.

**대체 경로.** 자동 보정이 G1 기준에 못 미치면 Caliscope(ChArUco)를 쓴다. 평면도 점 PnP 는 실측 평면도를 쓰지 않으므로 뺀다(수정 6).

## 4.4 보정 상태

| 상태 | 의미 | 운영 |
|---|---|---|
| UNCALIBRATED | 연결 직후, 추정 전 | 위치 기반 판단 불가, System Health UNSAFE_UNKNOWN |
| PROVISIONAL | AI 초기 추정 또는 기준 미달 | R1은 넓은 불확실성으로 동작, R2·R3·R4에 “확인 필요”, DEGRADED |
| CALIBRATED | 기준 충족, 동결 | 정상 운영, NOMINAL |
| DRIFTED | 운영 중 재투영 오차 증가 또는 스트림 해상도·화각 변경 | DEGRADED, 자동 재보정 시작 |

**CALIBRATED 기준(초기값).** 재투영 오차 중앙값 2px·p95 5px 이하, 사람 관측이 바닥 면적의 80% 이상을 덮음, 4대의 바닥 평면 차이 3cm 이하, 스케일 근거가 실측 정물(2개 이상, 서로 일치)이거나 사람 20명 이상의 키 통계이고, 다른 근거 하나와 교차 확인됨. 그리고 키를 아는 사람이 보정에 쓰지 않은 지점 3\~5곳에 섰을 때 머리 높이 오차 최대 15cm, 카메라 쌍별 위치 불일치 최대 15cm 이내(설치 직후 빠른 검산. 표본이 적어 p95를 쓰지 않는다). 현장에서는 실측하지 않으므로 절대 위치 정확도는 개발 교실의 G1·G2 실측으로 판정한다(수정 6). 재투영 오차는 모델과 관측이 맞는다는 뜻일 뿐 World 좌표가 정확하다는 뜻이 아니므로, 이 독립 검증을 통과하지 못하면 PROVISIONAL을 유지하고 대체 경로(ChArUco)로 전환한다.

## 4.5 보정 버전

- 후보 보정은 백그라운드에서 계산하고, 의미 있게 좋아졌고 검증을 통과할 때만 새 버전으로 원자적 전환한다.
- 모든 위치 계산 결과에 `calibration_version`을 붙인다.
- 정적 3D는 CALIBRATED 이후에만 생성하고, 생성에 쓴 보정 버전을 Scene 버전에 기록한다. 보정이 크게 바뀌면 해당 Scene을 재생성 대상으로 표시한다.
- 운영 중에는 지나가는 사람들의 keypoint로 재투영 오차를 계속 계산한다. 자동 보정 과정의 커버리지 계산으로 “카메라 3번이 너무 아래를 봄” 같은 설치 안내를 띄운다.
