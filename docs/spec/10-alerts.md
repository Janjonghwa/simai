# 10. 알림 채널

위험 판단은 카메라에 잡히는 모든 사람에게 같고, 달라지는 것은 전달 경로뿐이다. MVP 의 전달 경로는 노트북 로컬 경보와 관제 화면 경보(3.10)이고, 확인(ACK)은 관제 화면 또는 현장 확인 버튼으로 한다. 원격 휴대폰 알림(반장 PWA·Web Push)은 두지 않는다(10.1). 당사자에게 직접 닿는 워치는 확장이다(부록 C).

## 10.1 반장 PWA

폐기(v1.3). 반장 PWA·Web Push(VAPID)·시험 푸시·조치 티켓을 두지 않는다(16장). 관제 화면은 EC2 와의 연결 상태(STOMP 하트비트)를 표시하고(13.2), 시험 알림은 노트북 로컬 시험음으로 한다(3.10).

## 10.2 워치 (확장)

이동(v1.3) → 부록 C.
