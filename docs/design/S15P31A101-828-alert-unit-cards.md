# S15P31A101-828 알림 단위 관제 카드

관련 명세: 7.4, 13.2, 13.4. 계약 변경 없음.

관제·CCTV는 알림 하나를 카드 하나로 보이고 같은 사람의 다른 규칙은 합치지 않는다. 같은 규칙·구역이며 앞 사람의 트랙이 사라지고 마지막 갱신에서 60초 안에 다른 번호로 발생한 경우만 화면에서 횟수로 연결한다. 생존 여부를 모르면 연결하지 않으며 살아 있는 두 사람은 합치지 않는다. 카드의 제목·상태·시각과 상세는 대표 알림 하나의 것이다. Tier 0 이벤트 병합과 기록은 바꾸지 않는다.

작업 중 경보 기록도 알림별로 표시한다. 지난 날 로그는 과거 시점의 생존 여부를 알 수 없어 합치지 않고 알림별로 표시한다. 달력·월간 요약의 서버 사건 집계는 기존 기준이라 표시 줄 수와 다를 수 있다. 이 차이는 후속 집계 정합성 작업이 필요하다.

구현: `features/events/incidents.ts`, `EventPanel`, `IncidentCard`, CCTV 분할 화면, 작업 기록, `history/pastEventRows.ts`. 시험과 목업 확인 결과는 작업 보고에 남긴다.

### 시연 상세와 목업

상세는 해당 알림의 등급·규칙, 대상·구역·시각·상태와 있는 경우 AI 설명을 먼저 보인다. 관리자 확인과 접힌 자세히에서 지표·사진·클립·처리·타임라인·구간 요약을 제공한다. 목업은 작업 시작 후 5초 안전모 미착용을 추가하고 PPE 상태와 네 종류 설명을 맞춘다. 종료 집계는 발생한 위험 2건과 주의 3건을 포함한다.
