# S15P31A101-822 세팅 UX

## 관련 명세·범위
- 명세 13장 세팅 흐름과 2026-11-20 UX 최종 결정에 따라 1단계(카메라·맵 준비)와 3단계(구역)를 조정했다.
- 범위: `front/apps/admin/src/features/setup/*`, `features/demo/demoZoneDrafts.ts`, `features/work/SetupStage.tsx`, `mocks/setup.ts`, `features/zones/ZonesPage.tsx`(접힌 `+ 구역 추가` quiet 단추) 및 각 시험.

## 정한 수치와 근거
- 새 맵 소요시간 안내: 약 10분 소요(① 배경 촬영 · 약 20초 / ② 카메라 확인 · 약 30초 / ③ 3D 맵 만들기 · 약 9분). 사용자 결정 문구이며 실제 워커 SLA 가 아니다.
- 오른쪽 열 배치: 1단계는 `SetupSplit fillMap` 으로 왼쪽 영상 카드와 높이를 맞추고 `CameraHeightPanel` 은 `grid grid-cols-2 gap-2` 로 늘이지 않는다.
- 「사용자 추가 구역」 구분선: 다크 청사진 바탕(`#0a1b33`)에서 `border-border/40` 이 거의 보이지 않아 `border-input/45` 반투명 점선(`border-t border-dashed border-input/45 pt-3`)을 사용한다.

## 버린 대안
- 카메라별 「연결됨」 상태표와 2D 시야 도식은 1단계에서 제거하고 옆 카메라 쌍 칩(`1·2 ✓`, `3·4 ⚠`)과 약한 쌍 방향 안내만 남겼다. 불명(`UNKNOWN`)·오래됨 상태는 양호로 간주하지 않는다.
- 시연 계정이 이전 맵 재사용으로 진입할 때 목업(`mocks/setup.ts`)은 처음부터 구역을 채우지 않고 AI 찾기 3초 뒤 2개 초안(단상 개구부 위험, 단상 구역 주의)만 보이게 했다. 동시에 실서버처럼 이전 맵 구역이 이미 들어온 경우에는 `demoZoneDrafts` 가 `isCarriedZone` + `sameZoneSpot` 으로 같은 자리의 가짜 초안을 제외해 중복 표시와 3D 겹침을 막는다. `pairDraftsWithCarried` 로 묶어 존재하지 않는 「이어 쓴 구역 확인」 카드를 안내하던 대안은 버렸다.

## 남은 위험
- `ZonesPage.tsx` 의 접힌 추가 단추(`addOnDemand`)를 `variant="quiet"`·`+ 구역 추가` 로 바꿨다. 다른 화면은 `addOnDemand` 를 쓰지 않으나, 공용 `ZonesPage.test.tsx` 는 `-820` 심각도 라벨(`경고`→`주의`) 변경과 함께 갱신했다.
- 실서버 백엔드에서 시연 계정 재사용 시 `zones/seed` 가 기존 구역을 내려주는 경우, 겹치는 가짜 초안이 빠지면서 `AI 위험 구역 초안` 패널에 빈 상태 문구가 보일 수 있다(기존 구역은 아래 `사용자 추가 구역` 에 `이전 맵` 표시로 남는다).
