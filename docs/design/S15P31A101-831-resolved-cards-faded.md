# S15P31A101-831 해소 알림 표시

- 명세 13.4의 알림 단위 카드와 현재 실행 범위 필터를 유지하며, 해소 카드는 기존 반투명 표시와 함께 해소 시각을 보인다. 선택·상세 동작은 공용 카드를 그대로 쓴다.
- 이번 실행의 해소 목록에서 네 건 제한을 제거한다. 패널은 기존 세로 스크롤을 사용하며 실행이 없거나 바뀌면 기존 시작 시각 필터가 적용된다. 사람 소실 카드는 해소가 아니므로 해소 시각을 붙이지 않는다.
- 시연에서는 17·25초에 기존 이벤트 ID와 증가한 순번으로 해소를 발행하고, PPE 상태도 25초에 착용으로 바꾼다. 작업 보고 집계는 발생 전이만 세어 네 건(위험 2·주의 2)을 유지한다.
- 검증: 이벤트·CCTV·목업·레이아웃 테스트, 타입 검사, 목업 빌드와 시간별 화면 촬영. 실제 서버의 긴 실행에서 발생하는 메모리·목록 렌더링 비용은 실측하지 않았다.

- 상세 창은 AI 설명이 있을 때만 제목과 함께 표시하고, 접힌 이벤트 클립에서 관리자용 영상과 존재하는 사진만 보인다. 규칙·처리·타임라인·구간 요약 요청은 상세에서 뺐다. 기존 상향·요약 제어와 규칙 패널은 독립 기능 시험에서 쓰여 아직 코드에 남아 있다.
- 시연 빌드만 시험 클립 업로드 대기를 생략한다. 실제 서비스·일반 개발 목업의 대기와 관리자 권한 제한은 유지한다. 시연 클립은 실제 촬영 결과가 아닌 시험 패턴이다.
