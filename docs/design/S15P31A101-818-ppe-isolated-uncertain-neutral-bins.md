# S15P31A101-818 PPE: 고립된 ID 불확실 사람은 판정에 쓰고, 판정 없는 칸 2칸을 허용한다

관련 명세: 5.5(사람과의 연결: ID 불확실 표본 제외, 상태 전환: 미착용 창). 선행: -653(ID 불확실 칸 건너뛰기·3초 초과 초기화), -654(미착용 창 빈 칸 1칸), -766(칸 결합, 0.7.0), -769(local ID 다툼, 0.8.0).
명세 반영: 같은 MR 에서 5.5 두 곳과 개정 이력(v1.3 수정 88)을 고친다. 계약 변경 없음(`ppe_state.policy_version` 값만 `ppe-policy-0.9.0`).

## 바꾼 것

### 1. 고립된 ID 불확실 사람 (`isolated_uncertain_radius_m = 2.0`)

- `ai/services/ppe/loop.py` `isolated_world_ids`: 공유 문서의 트랙 중 고립된 트랙을 고른다. 조건은 셋이다.
  - Tier 0 `identity_confidence == IDENTITY_UNCERTAIN` 이다.
  - 자기 `position_xy` 를 안다.
  - 다른 트랙(`track_lifecycle` 이 `LOST` 가 아닌 것)이 모두 수평 2 m 밖이다. 다른 트랙 위치를 하나라도 모르면 고립으로 보지 않는다.
- `frame_observations` 는 이 결과를 `PersonObservation.isolated` 로 싣는다.
  - 공유 문서의 `avatar_update_hold` 는 Tier 0 불확실이면 항상 켜진다(`services/tier0/perception.py` `avatar_metadata`).
  - 그래서 예외는 Tier 0 가 `IDENTITY_UNCERTAIN` 일 때만 준다. 불확실이 아닌데 보류만 걸린 트랙은 지금처럼 건너뛴다.
- `ai/src/simai_ai/ppe/association.py` `ppe_uncertain`: Tier 0 불확실이어도 고립이면 False 를 돌려준다. `associate_frame`(표본을 막을지)과 `PpeJudge.ingest`(칸 건너뛰기·불확실 3초 초기화·local ID 다툼) 모두 이 함수를 쓴다.
- 결과: 고립된 불확실 사람은 PPE 판정에서 확실한 사람과 똑같이 다뤄진다. Tier 0 의 불확실 표시와 Risk·화면의 다른 판정은 그대로다.

### 2. 중립 칸 (`not_worn_max_neutral_bins = 2`)

- `ai/src/simai_ai/ppe/state.py` `combine_bin`: 표본은 있는데 모두 판정 없는 칸을 `B_NEUTRAL` 로 낸다.
  - 판정 없음 사유는 검출 없음 `NO_DETECTION`, 머리 불선명 `REGION_NOT_CLEAR`, 영역 안 보임 `REGION_NOT_OBSERVABLE`, 관절 미관측 `KEYPOINTS_NOT_OBSERVED` 넷이다.
  - 모호 사유(두 사람 겹침 `SHARED_DETECTION`, 착용·미착용 동시 검출 `CONFLICTING_CLASSES`, 부분 겹침 `PARTIAL_OPPOSITE_OVERLAP`)가 하나라도 있으면 지금처럼 `UNKNOWN` 칸이다.
- `_not_worn_window` 의 조건은 넷이다.
  - 빈 칸은 1칸까지(지금과 같음).
  - 중립 칸은 2칸까지.
  - 빈 칸 + 중립 칸은 2칸까지.
  - 나머지는 모두 미착용이고, 마지막 칸도 미착용이어야 한다(지금과 같음).
- 착용 확정 조건(착용 5/6 칸, 마지막 착용)은 바꾸지 않았다. 중립 칸은 착용 칸으로 세지 않는다.
- 중립 칸은 근거를 더하지 않는다. 그래서 미착용 근거 시각과 10초 만료는 그대로다.
- 순수 병합 칸 합치기(`_merge_result`)에서 중립 칸과 미착용 칸이 엇갈리면 지금처럼 `UNKNOWN` 칸이 된다(보수적).

### 공통

- `POLICY_VERSION` 을 `ppe-policy-0.9.0` 으로 올렸다.
- 두 값 모두 끌 수 있다. `isolated_uncertain_radius_m = 0`, `not_worn_max_neutral_bins = 0` 이면 0.8.0 동작이다.

### 미착용 확정 시각이 흔들림

같은 연습에서 미착용 확정까지 걸린 시간은 이렇게 갈렸다. 이론상 최소는 6칸 + 칸 닫힘 약 3.5초다.

- 18:03(0004): 6.4초. 14칸 중 3칸 불확실. 유효 칸이 3·5에서 1.5~2초씩 멈췄다.
- 18:14(0009, 작업 종료 뒤): 8초. 18칸 중 6칸 불확실.
- 18:12: 확정 없음. 35칸 중 30칸 불확실.

모든 카메라가 판정 없음만 낸 칸이 미착용 창에 하나 끼면, 그 칸이 창에서 밀려날 때까지(6칸, 약 3초) 미착용이 확정되지 않는다. 고개를 돌리거나 손이 머리를 가리는 한 순간이면 생긴다. 이 칸에는 착용 근거가 없어 미착용을 막을 이유가 약하다.

## 버린 대안

- **검출 기준 낮추기**: 이 장면의 미착용 점수는 0.68 이상이라 효과가 없다. 착용 오검출만 늘어난다.
- **Tier 0 불확실 사유를 PPE 로 넘겨 사유별 판단**: 더 정확하다. 그러나 Tier 0 공유 문서 변경과 재배포가 필요하고, 이 장면이 어느 사유였는지도 확인할 수 없다. 시연 전 위험이 크다.
- **미착용 창 6 → 4칸**: 기본 지연이 3.5초에서 약 2.5초로 줄지만, 칸이 빠지는 문제는 그대로이고 오경보가 는다.
- **불확실 3초 초과 초기화 완화(-769 2안)**: 고립 예외가 혼자 선 경우를 이미 덮는다. 가까이 선 경우는 맞바꿈 위험 때문에 그대로 둔다.

## 불변 조건

- 2 m 안에 다른 트랙(`LOST` 제외, 가림·임시 ID 포함)이 있으면 불확실 사람은 지금처럼 건너뛴다. 같은 사람의 유령 ID 가 옆에 생긴 경우도 보수적으로 건너뛴다.
- 착용·충돌·모호 칸은 미착용 창을 지금처럼 막는다. 중립 칸은 근거 시각을 늘리지 않는다.
- 상태 초기화 조건(순수 병합이 아닌 차수 상승, 확실한 사람의 local ID 주인 변경)은 그대로다.

## 잔여 위험

- Tier 0 위치가 틀려 실제로 가까운 두 사람이 2 m 밖으로 계산되면, 섞인 관측의 PPE 표본이 들어갈 수 있다. 0.8.0 에서는 버려지던 칸이다.
- 혼자 선 사람의 단독 오검출도 판정에 들어간다. 예를 들어 검은 조끼(카메라별 15~28% 미착용, -766)나 손에 든 안전모가 그렇다. -766 칸 결합과 6칸 창이 그대로 거른다.
- 녹화 재판정은 카메라 4 한 대, 화면 녹화 화질 기준이다. 다른 카메라가 착용을 잘못 냈다면 확정이 늦어질 수 있다(-766: 미착용 1대 + 착용 = 착용 칸). 리허설에서 확인해야 한다.
