# S15P31A101-830 VLM 기본 꺼짐

- 2026-11-20 시연 결정: 지연 때문에 VLM 기본값을 끈다. 명세 5.4는 VLM 근거·요약을 MVP/M3로 기술하므로 기본 운영 동작에 차이가 있으며 명세 정리가 필요하다. Tier 0 판정과 알림은 바뀌지 않는다.
- 서버 `simai.gpu.vlm-enabled`는 기본 false이며 `SIMAI_GPU_VLM_ENABLED=true`로 다음 GPU 세션부터 켠다. 화면·DB·계약 변경은 없다.
- 서버는 꺼진 경우 `SIMAI_BOOT_DISABLE=vllm`을 전달한다. 부팅기는 명시 서비스 목록 또는 기존 VRAM별 축소를 먼저 정하고 제외 목록을 적용한다. 전체 목록을 서버에서 강제하면 GPU별 PPE·워커 선택과 충돌하므로 제외 방식을 쓴다. 의도된 제외는 `svc_vllm` 정보로, 그 밖의 미기동은 경고로 보고한다.
- 워커는 vLLM이 없으면 근거·구간 요약의 대여를 생략한다. 구역 초안은 기존 기하 폴백을 사용한다. 이벤트 사진·클립 업로드는 Tier 0 별도 경로다(명세 5.2·5.4).
- 상세 창은 현재 활성 세션의 `svc_vllm` 보고를 받은 관리자에게 AI 설명을 숨긴다. GPU 상태를 모르면 기존 표시를 유지하며 목업 빌드는 기존 표시를 유지한다. 비관리자는 GPU 상태 API 접근 권한이 없어 꺼짐을 판별할 수 없다.
- 남은 위험: 이미 대기열에 등록된 구간 요약은 VLM을 다시 켜기 전까지 대기할 수 있다. 기존 서버의 마감·정리 정책을 따른다. 실제 GPU 부팅 및 업로드는 현장 검증이 필요하다.
