# S15P31A101-836 상세 클립·상태와 작업 시간

- 관련 명세: 5.1·11.5의 이벤트 영상, 7.3·7.4 및 13.4의 관제 경보 표시. 서버 확인 규칙과 계약은 바꾸지 않는다.
- 관리자 상세는 기존 클립·사진 대상 판정으로 접힘 칸을 결정한다. 대상 클립이 준비 중일 때는 기존 준비 안내를 유지한다. 실제 생성 전인 대상도 표시하므로 준비 상태를 숨기지 않는다.
- HIGH·CAUTION 상세 상태는 안내로 표시하고 카드의 미확인 상태 글은 CRITICAL에만 표시한다. 경보 배너·확인 버튼·소리의 판정은 유지한다.
- 공통 세션 바에 시작 시각과 매초 갱신되는 경과를 표시한다. 시작 시각이 없으면 추정하지 않는다. 1시간 전후 경과 형식을 시험한다.
- 잔여 위험: 영상 대상 여부는 기존 LIVE·심각도 규칙으로 판단하므로 서버의 개별 영상 생성 실패 여부는 접힘 칸 안에서 확인한다.
- 2차: 상세 확인 버튼을 제거하고 위험 확인 시각을 표시한다. 배너는 등급·갱신 최신순이며 확인 시 다음 대기 건을 선택한다. 목업은 낙상 45초·진입 50초 해소와 작업자의 서쪽 이동을 기록하고, 목업 시연 계정의 두 맵 선택 모두 세션 생성 뒤 구역 단계로 직행한다.
- 미해결: 해소된 미확인 위험은 현재 `isAlarming`에서 제외되고 서버 `EventAckService`와 목업이 해소 후 ACK를 409 `EVENT_RESOLVED`로 거절한다. 서버 확인 규칙을 바꾸지 않는 조건에서는 배너에서 확인할 수 없다. 요구 충족에는 서버·계약/명세의 확인 규칙 결정이 필요하다. 시연 화면에서 해소 후에는 최근 해소 카드로만 보인다.
