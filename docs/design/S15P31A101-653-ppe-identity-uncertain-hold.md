# S15P31A101-653 PPE 상태 누적에서 ID 불확실 칸 건너뛰기

관련 명세: 5.5(사람과의 연결·상태 전환), 6.2(PPE 상태), 7.2(R9·R11), 15.1(G9·G6-R9·G6-R11). 선행: -491(PPE 판정), -507(PPE 서비스), -567(5 Hz 입력 칸). 명세 반영: v1.3 수정 74(같은 MR).

## 결정

- ID 대응이 불확실한 사람(Tier 0 `IDENTITY_UNCERTAIN`, 또는 `avatar_update_hold` 로 넘어온 분할 대기·swap 의심)의 프레임이 하나라도 있는 500 ms 칸은 **건너뛴다**. 그 칸의 표본은 창에도 근거에도 넣지 않고, 확정 상태(WORN·NOT_WORN)는 그대로 둔다. 근거를 더하지 않으므로 만료(마지막 유효 근거 + 10초)는 늘어나지 않는다.
- 확정은 **최근 5초(10칸) 안의 유효 6칸**으로 한다. 착용 5칸 이상 + 마지막 유효 칸 착용, 미착용 6칸 모두.
- 상태를 바로 초기화하는 것은 `identity_revision` 상승(분할·swap 교정 포함), 같은 카메라 local ID 의 주인 변경(2초 안), **ID 불확실이 3초를 넘게 이어질 때**다. 확실한 프레임이 하나 오면 불확실 구간은 끊긴다.
- 화면·판정 사유: 확정 전(UNKNOWN)에 불확실 칸이 오면 사유를 `IDENTITY_UNCERTAIN` 으로 보이고, 유효 칸이 다시 오면 그 칸의 사유로 바꾼다(전에는 다시 확정될 때까지 고착). 반대 근거·카메라 충돌·revision·대응 변경 사유는 그대로 고착한다.
- `policy_version` `ppe-policy-0.1.0` → `ppe-policy-0.2.0`. `ppe_state` 스키마 변경 없음(`reason` 은 자유 패턴이고 새 코드를 만들지 않는다). Tier 0 R9·R11 변경 없음(같은 World ID·`identity_revision`·만료 전 상태만 쓰는 규칙이 그대로 안전장치다).

## 바꾼 것

- `ai/src/simai_ai/ppe/state.py`: `TrackState` 에 `skipped_bins`·`uncertain_since`·`uncertain_reset`. `ingest` 는 불확실 프레임마다 그 칸을 건너뜀으로 표시하고 표본을 받지 않으며, 불확실이 `uncertain_reset_ms` 를 넘으면 한 번 초기화한다. `_window` 는 최근 `window_span_bins` 안의 건너뛰지 않은 칸 중 마지막 `window_bins` 개, `_step` 은 건너뛴 칸에서 결과·근거를 남기지 않는다.
- `ai/src/simai_ai/ppe/config.py`: `window_span_bins = 10`, `uncertain_reset_ms = 3000`, `POLICY_VERSION = "ppe-policy-0.2.0"`.
- `ai/src/simai_ai/ppe/association.py`·`ai/services/ppe/loop.py`: 변경 없음(불확실 사람의 표본은 연결 단계에서 이미 UNKNOWN 이고, 판정 모듈이 받지 않는다).
- 명세 5.5·6.2, README 개정 이력, `docs/design/ppe-service.md` 관측 고르기 행.

실측 identity_confidence 시계열을 실제 `PpeJudge` 에 넣은 재생(칸마다 프레임 1개, 검출은 늘 명확하다고 가정한 상한):

|---|---|---|
| 2인 착용자(WORN) | 33.1% | 49.4% |
| 2인 미착용자(NOT_WORN) | 41.9% | 89.6% |
| 1인 구간 미착용자 0001 / 0038 / 0047 / 0028 / 0010 | 53.1 / 62.6 / 63.9 / 26.8 / 0.0% | 81.6 / 76.6 / 88.5 / 40.9 / 5.6% |

- 3초(D2): 초기화 문턱 2~4초를 같은 시계열로 비교했을 때 미착용자 확정 상한 72.7~86.8%, 불확실 동안 이전 상태를 들고 있는 시간 18~26%로 이득과 노출이 비슷하게 함께 커졌다. 확정 창 길이(유효 6칸 = 3초)와 같게 두어 설명이 쉽다.
- 5초(D3): 유효 칸이 띄엄띄엄 흩어진 오래된 근거로 확정하지 않게. 초기화 없이 범위만 둔 경우(5초)와 비교해 미착용자 상한 94.2% → 81.5%(초기화 포함)로 노출을 줄였다.
- 보류(분할 대기·swap 의심)도 불확실과 같이(D4): Tier 0 는 swap 을 확정하면 두 트랙의 `identity_revision` 을 올리므로(`ai/src/simai_ai/tracking/world_track.py` 의 swap 되돌리기) 확정된 교환은 revision 초기화로 걸린다.

## 버린 대안

- 이전 규칙(불확실 프레임마다 초기화): Tier 0 의 1초 불확실 유지(`uncertain_hold_ms`)와 겹쳐 짧은 깜빡임마다 3초 창을 다시 쌓아 확정이 거의 나지 않았다(위 표).
- 초기화 없이 건너뛰기만: 확정률은 가장 높지만(미착용자 상한 94%) 불확실이 길게 이어져도 이전 상태를 10초까지 들고 있다.
- 3D 표시만 바꾸기(UNKNOWN 표현): UNKNOWN 비율 자체가 줄지 않아 시연에 효과가 없다. 별도 과제로 둔다.
- 사람 구분 없이 착용·미착용만 판정: 워치 경보(World ID → 배정 워치)와 3D 표시가 사람별이라 쓸 수 없다.

## 잔여 위험

- 두 사람이 붙었다 떨어지며 ID 가 바뀌었는데 Tier 0 가 swap 을 확정하지 못하고 3초 안에 불확실이 끝나면, 앞사람의 확정 상태가 최대 만료(10초)까지 뒷사람에게 남을 수 있다. 착용 상태가 남으면 R9·R11 누락, 미착용이 남으면 오경보(둘 다 CAUTION·관제 화면 안내). G6 시험에 "근접 교차 뒤 착용·미착용 교환" 사례를 넣는다.
- Tier 0 ID 불확실이 수십 초 이어지는 장면(2026-11-12 1인 구간 0010·0031)에서는 이번 변경으로도 확정이 거의 나지 않는다. Tier 0 ID 안정화는 실시간 추적·World 상태 에픽의 일이다.
- 재생 수치는 검출이 매 칸 명확하다고 가정한 상한이다. 실제 확정률은 검출 빈도·머리 선명도에 따라 낮다.
