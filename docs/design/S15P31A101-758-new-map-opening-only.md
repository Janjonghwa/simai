# 새 맵은 AI 초안(개구부 하나)만으로 시작하기 (S15P31A101-758)

-629(새 모델 + World 이어짐의 구역 확인)와 -671(AI 초안이 시연 개구부 하나를 잡게 하기)의 후속이다.
관련 명세: 8.2(F-06 입체 Geo-fencing, 현장 세팅 초안·이관 구역), 12.6(세팅 REST).
앞선 약속: `docs/design/S15P31A101-629-setup-zone-confirm.md`, `docs/design/S15P31A101-671-zone-draft-demo-opening.md`.

## 왜

-629 이후 새 모델(NEW) + World 이어짐 세팅은 구역 단계에 들어오면 지금 관제 구역을 모두 '확인 필요'로 채웠다. 시연 현장은 -671 로
AI 초안이 개구부 하나를 잡는데, 이전 세팅의 같은 개구부가 함께 이어 와 같은 자리에 구역이 둘 생기고, 시연과 무관한 이전 구역까지
하나씩 확인해야 했다. 새 맵은 AI 초안만으로 시작하고, 이전 구역은 관리자가 원할 때만 불러온다.

## 바꾼 흐름

| 세팅 | 구역 단계에 처음 들어올 때 | 이전 구역 |
|---|---|---|
| 이전 모델 재사용(REUSE) | 그대로(-629·-714: 지금 관제 구역 또는 고른 맵의 구역으로 채움, 확인 표시 없음) | - |
| 새 모델 + World 이어짐 | **채우지 않음**(빈 목록 + AI 초안) | 「이전 구역 불러오기」를 누르면 확인 필요로 더함 |
| 새 모델 + World 끊김 | 채우지 않음 | 불러올 수 없음(409) |

- 처음 채우기(`POST .../zones/seed`)는 재사용만 채운다. 화면(`useSeedSetupZonePlan`)도 재사용 세션에서만 부른다.
- 불러오기(`POST .../zones/import-previous`, 아래)는 지금 목록에 덧붙인다(저장 여부와 무관, revision + 1). 이미 목록에 있는 구역은 다시
  넣지 않으므로 두 번 눌러도 같다. 더한 구역은 `needs_review: true`(레이아웃이 만든 구역 제외, -629 와 같음).
- 오른쪽 칸: 이어 온 구역이 없으면 「이전 구역」 카드(설명 + 「이전 구역 불러오기」, 결과 안내)를, 있으면 -629 의 「이어 쓴 구역 확인」
  카드를 보인다. 확인 카드 목록은 이어 온 구역(zone_id 가 있는 항목)만 보인다. 새로 그리거나 수락한 구역은 구역 편집에서 본다.
- AI 초안이 0건이면(분석 끝남 또는 실패) 초안 패널이 "AI 가 개구부를 찾지 못했어요 — 직접 그려 주세요"를, World 이어짐이면
  "… 직접 그리거나 이전 구역을 불러오세요"를 보인다(`role="status"`). 남은 초안이 없을 뿐이면 예전처럼 "AI 구역 초안 없음".

## 같은 자리 판정

서버 `SetupZoneOverlap` 과 화면 `zoneOverlap.ts` 가 같은 기준을 쓴다.

- 높이 범위가 겹친다(한쪽이라도 높이가 없으면 겹친다고 본다).
- 바닥 다각형 교집합이 작은 쪽 면적의 **0.5** 이상이다.
- 작은 쪽 면적이 큰 쪽의 **0.25** 이상이다(넓은 구역 안에 든 작은 구역은 다른 구역).
- 교집합은 AI 다각형의 볼록 껍질로 이어 온 다각형을 자른다(Sutherland–Hodgman). AI 초안 구역은 볼록 다각형을 바깥으로 민 볼록 다각형이라
  손실이 없고, 이어 온 구역은 오목해도 된다.

쓰는 곳은 두 군데다.

1. **불러오기(서버):** 목록에 이미 있는 AI 초안 구역(`source: AI`, 본문 있음)과 같은 자리인 이전 구역은 넣지 않고 응답
   `import_skipped` 에 이름을 싣는다. 화면은 "AI 초안 구역과 같은 자리인 「…」은(는) 빼고 불러왔어요."로 알린다.
2. **아직 수락하지 않은 초안(화면):** 불러온 뒤에 초안이 도착하거나 초안을 수락하기 전에 불러오면, 같은 자리인 이어 온 구역과 초안을
   `pairDraftsWithCarried` 가 짝짓는다(초안 하나는 가장 많이 겹친 구역 하나와, 구역 하나는 초안 하나와만). 짝지은 초안은 초안 목록에서
   감추고 확인 카드의 그 구역 행에 「이전 것 유지」(확인 + 초안 버리기)·「AI 초안으로」(이어 온 구역 빼고 초안 구역 더하기, PUT 한 번 +
   초안 수락 표시) 중 하나를 고르게 한다. 짝지은 행에는 「확인」 단추를 두지 않는다.

## 명세와 다른 점

- **8.2:** "`FULL_SETUP` 에서 이전 세팅의 위험구역을 고정 좌표계(`world_anchor.accepted = true`)로 이어받으면 모든 이관 구역은 …
  `needs_review = true` 상태로 시작"은 그대로 맞다. 다만 이어받기가 더 이상 자동이 아니다: 새 모델은 이관 구역 없이 AI 초안만으로
  시작하고, 관리자가 「이전 구역 불러오기」를 눌렀을 때만 이관한다. 이관 구역 높이 변화 판정(-630)·AI 의견(-631)·확인 전 완료 금지는
  불러온 구역에 그대로 적용된다. 명세 반영은 명세 담당에게 넘긴다.
- **12.6:** 세팅 REST 표에 새 경로가 필요하다(아래). 표의 `zones/seed` 설명("VLM 초안 시드")도 실제(재사용 목록 채우기)와 다르다.

## 새 경로 (12.6 에 더할 것)

| 메서드 | 경로 | 설명 | 권한 |
|---|---|---|---|
| POST | `/api/setup-sessions/{setupSessionId}/zones/import-previous` | 「이전 구역 불러오기」. 새 모델 + World 이어짐 세팅의 목록에 지금 관제 구역을 확인 필요로 더한다. 목록의 AI 초안 구역과 같은 자리인 구역은 빼고 `import_skipped`(문자열 배열, 구역 이름)에 싣는다. 응답은 `GET .../zones` 와 같고 `import_skipped` 를 더한다. 재사용 세팅은 `zones/seed` 와 같다. | 관리자 |

오류: World 가 끊긴 새 모델 409 `SETUP_ZONE_WORLD_MISMATCH`, 완료·실패한 세팅 409 `SETUP_ZONES_CLOSED`, 카메라 확인 미통과 409
`SETUP_CAMERA_CHECK_NOT_PASSED`(-646, `zones/seed` 와 같음), 더한 뒤 목록 상한 초과 400 `INVALID_SETUP_ZONE_PLAN`(반쯤 더하지 않음).
계약(`contracts/`) 변경은 없다(세션 구역 목록은 계약 스키마가 없는 응답). 마이그레이션도 없다.
