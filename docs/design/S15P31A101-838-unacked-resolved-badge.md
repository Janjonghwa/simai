# S15P31A101-838 확인 없이 해소된 위험 표시

- 관련 명세: 7.4 알림, 13.4 관제 화면, 3.10 확인. 서버의 해소 후 확인 거절과 계약은 바꾸지 않는다.
- 해소된 CRITICAL 이벤트에 확인 기록이 없으면 최근 해소 카드와 상세 머리에 미확인을 표시한다. HIGH·CAUTION·INFO는 표시하지 않는다. 카드가 표시하는 최신 이벤트와 상세 대표 이벤트를 각각 기준으로 한다.
- 확인 기록 유무를 사용한다. 해소 상태를 처음 받은 경우 단계 시작 시각이 최종 갱신 시각으로 추정될 수 있어 활성 단계의 시각 판정을 재사용하지 않는다. 재개 전 확인 기록만 남은 경우 구간별 확인 여부는 계약의 확인 대상 순번이 없어 구별할 수 없다.
- 확인된 위험에는 별도 칩을 추가하지 않는다. 지난 날짜 다시 보기의 변경은 범위에서 제외한다. 검증은 이벤트·히스토리 시험과 목업 화면 촬영으로 한다.
