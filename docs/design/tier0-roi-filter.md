# Tier 0 관제 영역 밖 관측 필터 (S15P31A101-562)

- 관련 명세: 5.2의 교차 시점 연결과 임시 바닥 가설, 3.9의 촬영 시각 보간, 6장의 구역 유효 시간. 계약과 World 위치·접지는 바꾸지 않는다.
- 판정 tick의 구성 묶음에서 융합 시각에 유효한 구역 다각형을 골라, 전부를 감싸는 축 정렬 사각형 하나(`zone_envelope`)와 경계 밖 거리 `margin_m` 이내를 통과시킨다(Lead 검토: 구역별로 거르면 개구부 구역만 켜졌을 때 다가오는 사람이 1.5 m 안에 들기 전까지 지워져 R5 접근 경보가 늦다). 유효 구역이 없거나 설정이 꺼지면 모두 통과한다. 명시 작업 영역은 이번 범위에서 구현하지 않았다.
- `input.roi_filter.enabled` 기본 true, `margin_m` 기본 1.5 m(유한한 0 이상). 보간된 발목의 평균, 없으면 같은 프레임으로 보간한 bbox 하단 중앙을 왜곡 보정 후 Z=0 평면에 투영한다. 왜곡 보정 실패, 위쪽·수평 광선, 카메라 높이 이상 또는 발 위치 미상은 통과시킨다. 임시 투영은 필터에만 사용한다. 카메라별 제외 누계는 상태와 30초 stage_timing 로그의 `roi_filtered`, 소요 시간은 `roi_filter` 에 남긴다.
- 여유 근거: 카메라 높이 2.44 m, 발이 바닥에서 0.4 m 높고 카메라와 발의 수평 거리가 D이면, 바닥 가설의 추가 밀림은 `0.4/(2.44-0.4) × D ≈ 0.196D`다. D=7.65 m까지 약 1.5 m이며 거리 제한이 없으면 최대 밀림도 유한하지 않다. 발목은 실제 표면보다 높고 검출·보정 오차도 있으므로 1.5 m는 보장이 아니라 시연장 조정용 초기값이다.
- 버린 대안: 다각형 내부만 허용하면 단상 높이와 경계 오차로 작업자를 놓칠 수 있다. 고정 World 위치로 취급하거나 실패를 제외하면 정본 규칙과 안전 측 불확실성 처리를 어긴다.
- 검증: `ai/tests/tracking/test_roi_filter.py`의 4대 합성 관측에서 2명 내부·6명 외부를 비교하며 World 결과, 비활성 구역, 투영 실패, bbox 대체와 설정을 확인한다. SIM 결과는 제품 성능이 아니다.
- 남은 위험: 구역 바깥의 작업자, 구역 진입 전 접근과 높은 단상·먼 카메라·부정확한 보정·가림/오검출은 필터로 누락될 수 있다. 운영 전 실제 시연장 영상으로 구역 범위와 여유를 검증하고 필요하면 늘리거나 끈다. 성능 개선량과 실제 재현율은 현장 측정 전 미확인이다. 배경 누적·틀어짐 감시는 각각 -563·-564 범위다.
