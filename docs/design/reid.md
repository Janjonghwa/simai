# Re-ID 1단계: COPE 외형·얼굴 보조 특징 추출 모듈과 오프라인 검증 (S15P31A101-463)

     운영 실시간 루프에서는 `embed()` + COCO 17관절 기반 가시성(`estimate_part_visibility`) 조합을 기본으로 쓰는 것이 지연 대비 효율이 가장 좋다.
  2. Tier 0의 10 Hz(`100 ms`) 판정 루프 안에서 매 tick 모든 카메라 검출을 동기 추론하면 배치 8 기준 약 `74 ms`(노트북 RTX 4050 FP32 기준)가 걸리므로,
     **매 프레임 전수 추론 대신 (a) 트랙당 주기적 갤러리 갱신(예: 0.5~1.0 s 간격) 또는 신규·모호 클러스터 발생 시에만 배치 추론**하거나,
     검출 스레드/비동기 특징 갱신 주기로 분리해 Tier 0 10 Hz 판정 예산을 침범하지 않게 해야 한다.

## 4. 버린 대안

1. **COPE 원본 저장소(`C:/Users/SSAFY/simai-local/reid/cope`) 코드를 직접 수정하거나 저장소 안으로 복사하는 안**
   - COPE 원본(`cope/model.py`)은 `TransReID.__init__`와 `PromptLearner.__init__` 안에 `.to("cuda")`·`.cuda()`가 하드코딩되어 있고,
     CLIP 가중치 경로가 맞지 않으면 웹에서 자동 다운로드를 시도한다.
   - 외부 저장소를 직접 고치면 다른 작업 환경에서 재현이 깨지고 라이선스·출처 관리가 복잡해지므로,
     `COPEEmbedder._load_cope_model` 안에서만 초기화 문맥 래퍼로 자동 다운로드를 차단하고 CPU/GPU 디바이스 전환을 안전하게 감싸도록 구현했다.
2. **트랙 갤러리를 단일 평균(EMA / mean) 벡터 하나로만 유지하는 안**
   - 카메라 각도와 사람 방향(정면·측면·후면)에 따라 외형 벡터가 달라지는데 단순 평균을 내면 벡터가 중심부로 뭉개져 변별력이 떨어진다.
   - 실제로 10/29 녹화에서 `(camera_id, orientation_bin)` 다중 슬롯의 `max` 유사도(`98.08%`)가 `mean` 유사도(`81.73%`)보다 Top-1 정확도가 16.3%p 높게 측정되어,
     슬롯 기반 다중 표본 + `max` 유사도를 기본으로 채택했다.
3. **얼굴 인식을 주 재식별 신호로 쓰는 안**
   - 교실·로비 광각 카메라에서 뒷모습·측면 구간이 전체의 23~45%에 달하고 먼 거리에서는 40 px 미만으로 내려간다.
   - 무리하게 저해상도 얼굴을 복원하거나 추론하면 명세 규칙 8(지어낸 얼굴 금지)에 위배되고 오매칭이 늘어나므로,
     `min_face_size_px = 40` 및 정면 랜드마크 조건을 통과할 때만 보조 가중치로 더하도록 제한했다.

## 5. 잔여 위험

1. **유사 복장(교복·단체복) 착용 시 외형 변별력 저하**
   - 평가 녹화(`10/29`, `11/03`)의 피험자들은 서로 다른 상·하의를 입고 있어 Cross-camera ROC-AUC가 `0.9901`로 매우 높게 나왔으나,

2. **부분 가림(`co_visibility < 0.65`) 구간의 분리도 하락**

   - `co_visibility_confidence`가 낮을 때는 외형 보조 가중치를 자동으로 줄이고, `DORMANT` 장기 재연결은 `torso`를 포함한 공가시성이 `0.65` 이상일 때만 허용해야 한다.
