# 워치 앱 뼈대와 개발 환경 (S15P31A101-335)

갤럭시워치(Wear OS) 전용 최소 앱(기획서 부록 C.6, FR-43~47, NFR-12)의 첫 단계. 저장소 최상위 `watch/` 에 Kotlin·Gradle
프로젝트를 두고, EC2 주소·기기 토큰을 넣고 상태를 보는 화면까지 만든다. 위험 알림 화면·등급별 진동·확인 단추는 S15P31A101-390
(아래 "알림 화면"). EC2 연결(I4)·ACK 전송은 S15P31A101-337, 걸음 특징은 -339.
빌드·설치 절차는 `watch/README.md`.

## 구성

| 위치 | 하는 일 |
|---|---|
| `watch/gradle/libs.versions.toml` | 판 고정(아래 표) |
| `watch/app/src/main/AndroidManifest.xml` | 워치 전용(`android.hardware.type.watch`), 휴대폰 없이 혼자 동작(`wearable.standalone`), 백업 끔 |
| `config/WatchConfig.kt` | EC2 주소·기기 토큰 검증. 토큰을 `toString`·예외 문장에 넣지 않음 |
| `config/WatchConfigStore.kt` | 앱 전용 SharedPreferences 에 저장·읽기·지우기 |
| `ConfigActivity.kt` | adb `am start` 로 설정을 넣는 화면 없는 입구 |
| `MainActivity.kt` | 설정 상태 화면(Wear Compose Material 3) |
| `app/src/test/.../WatchConfigTest.kt` | 주소·토큰 검증 단위 시험(JVM) |

## 명세가 비워 둔 곳에서 정한 것

| 항목 | 정한 값 | 근거 |
|---|---|---|
| 위치 | 저장소 최상위 `watch/`, Android Studio 는 이 폴더를 프로젝트로 연다 | 파트별 최상위 폴더 관례(`server/`·`front/`·`gateway/`). 서버 Gradle 과 빌드를 섞지 않는다 |
| 패키지 | `com.ssafy.simai.watch` | 서버 `com.ssafy.simai` 아래 |
| minSdk / targetSdk / compileSdk | 30 / 36 / 37 | Wear OS 3 = API 30(워치4 이상). Wear Compose 1.7.1 이 compileSdk 37 이상을 요구한다(AAR 메타데이터 검사). 실행 동작은 targetSdk 36 으로 둔다 |
| 판 | AGP 9.4.1(2026-09-18), Kotlin 2.4.21(10-08), Wear Compose 1.7.1(10-07), activity-compose 1.13.0, JUnit 4.13.2, Gradle 9.8.1(서버와 같음) | 나온 지 2주 넘은 안정판. AGP 9.5.0(10-28)·Gradle 9.8.2(10-19)는 2주가 안 돼 뺐다. AGP 9 는 Kotlin 을 내장해 `kotlin-android` 플러그인을 쓰지 않고 Compose 컴파일러 플러그인만 단다 |
| 설정 넣는 방법 | adb `am start` 로 `ConfigActivity` 에 `ec2_base_url`·`device_token` 을 함께 넘긴다 | 워치 키보드로 긴 토큰을 칠 수 없다. 이 단계의 "설정 화면(최소)" 은 상태 표시 + adb 입력으로 한다 |
| 설정 입구 보호 | `ConfigActivity` 에 `android:permission="android.permission.DUMP"` | adb 가 부르려면 exported 여야 해 다른 앱도 부를 수 있다. DUMP 는 adb shell 이 갖고 일반 앱은 받을 수 없어, 다른 앱이 주소를 바꾸거나 설정을 지우지 못한다 |
| 주소·토큰을 함께만 바꿈 | 둘 중 하나만 오면 거부, `clear` 와 새 값을 같이 주면 거부 | 주소만 바꿀 수 있으면 저장된 토큰이 다른 서버로 간다. 지우기와 새 값이 같이 오면 의도를 알 수 없다 |
| 저장 실패 | `commit()` 이 false 면 "저장하지 못했다" 로 알린다 | 저장이 안 됐는데 성공으로 보이면 시연 워치가 연결되지 않는 까닭을 찾기 어렵다 |
| 규칙에 안 맞는 저장값 | 읽을 때 지운다 | 규칙이 강해져 저장값이 무효가 되면 화면은 "설정 안 됨" 인데 토큰만 남는다 |
| 주소 규칙 | https·호스트 필수, 계정·query·fragment·토큰 불가, 루프백 http 도 불가 | 노트북 게이트웨이 `validate_base_url`(gateway/site_alert heartbeat.py)과 같게 해 기기 토큰 다루는 규칙을 하나로 둔다 |
| 숨긴 토큰 찾기 | 주소 원문·unquote·unquote_plus 세 형태에서 토큰 원문·quote 형태를 찾는다. unquote 는 Python 과 같이 깨진 `%` 를 그대로 둔다 | 게이트웨이와 같은 형태들. `java.net.URLDecoder` 는 깨진 `%` 하나에 예외를 내고 `+` 를 공백으로만 풀어 숨긴 토큰을 놓친다(리뷰 지적) |
| 토큰 저장 | 앱 전용 SharedPreferences(MODE_PRIVATE), `allowBackup=false` | 다른 앱이 읽을 수 없고 백업으로 밖에 나가지 않는다. Jetpack Security(EncryptedSharedPreferences)는 지원 종료라 쓰지 않는다. 기기 분실 대비는 토큰 폐기(NFR-12)로 한다 |
| 화면 문구 | 호스트만 보이고 토큰 값은 보이지 않는다 | 화면 촬영·어깨 너머로 토큰이 새지 않게 |

## 알림 화면 (S15P31A101-390)

팀이 반장 휴대폰 PWA 를 버리고(2026-10-31) 위험 알림을 워치로만 보내기로 해서, 알림이 왔을 때 보이는 화면·진동·확인을 만들었다.
서버(I4: -334 계약, -336 연결, -338 발송)가 아직 없어 앱 안에서만 도는 알림으로 만들고, I4 가 오면 알림이 들어오는 곳만 바꾼다.

| 위치 | 하는 일 |
|---|---|
| `alert/WatchAlert.kt` | 알림 한 건(watch_alert)의 값과 검사. 칸 이름은 [AlertFields]. 잘못된 값은 IllegalArgumentException |
| `alert/AlertBoard.kt` | 받은 알림의 상태(ACTIVE·EXPIRED·ACKED)를 들고 있는 순수한 값. 시각을 받아서 JVM 에서 시험한다 |
| `alert/VibrationPattern.kt` | 진동 패턴 표와 등급별 기본값 |
| `alert/AlertVibrator.kt` | 패턴을 워치 진동기로 낸다(API 30 은 `Vibrator`, 31+ 는 `VibratorManager`) |
| `alert/AlertAcker.kt` | 확인을 EC2 로 보내는 인터페이스. 지금은 logcat 에만 남긴다(-337 이 실제 전송으로 바꾼다) |
| `alert/LastAlertStore.kt` | 마지막 알림 시각만 저장(상태 화면용). 알림 내용은 저장하지 않는다 |
| `AlertActivity.kt` | 알림 화면 입구. 잠금 화면 위에 띄우고 화면을 켠다. 앱 안에서만 부른다(exported 아님) |
| `ui/AlertScreen.kt` | 검정 바탕 알림 화면: 남은 시간 링, 등급 아이콘, 큰 한 단어, 방향, 아래쪽 큰 확인 단추. 확인함 화면도 여기 |
| `ui/AlertIcon.kt`, `ui/SeverityStyle.kt` | 등급 아이콘 그리기(위험 채운 팔각형, 경고 삼각형 윤곽, 주의 원 윤곽, 확인 체크), 등급 글자·색·모양 표 |
| `ui/WordSize.kt`, `ui/ClockText.kt` | 한 단어 글자 크기(화면 폭과 글자 수로 정함), 시각·기한 경과 글자 |
| `ui/StatusScreen.kt` | 대기 화면: 연결 상태와 마지막 알림, 개발용 값은 아래로 스크롤 |
| `src/debug/.../DebugAlertActivity.kt` | 가짜 알림 입구(debug 빌드 전용, adb). 사용법은 `watch/README.md` |

### 명세가 비워 둔 곳에서 정한 것

| 항목 | 정한 값 | 근거 |
|---|---|---|
| 등급 | CRITICAL 위험 / HIGH 경고 / CAUTION 주의. INFO 는 받지 않는다 | 7.3 채널 표: CRITICAL·HIGH 는 경보, CAUTION 은 약한 진동(FR-45). 관제 앱 배지와 같은 이름(▲▲ 위험, ▲ 경고, ! 주의) |
| 진동 패턴 | 위험 `DANGER_LONG` 0.8초 켜고 0.2초 끄기를 되풀이 / 경고 `CAUTION_DOUBLE` 0.15초씩 두 번 / 주의 `CAUTION_WEAK` 0.12초 약하게 한 번 | FR-45 "주의 짧게 두 번, 위험 길게 연속, CAUTION 은 약한 진동". DB 의 vibration_pattern 값(`CAUTION_DOUBLE`·`DANGER_LONG`)을 그대로 쓰고, 약한 진동은 앱 안의 값이다(-334 에서 맞춘다). 서버가 패턴을 주면 그것이 우선이고 없으면 등급으로 정한다 |
| 되풀이 | 위험만 확인될 때까지(또는 기한까지) 되풀이한다. 경고·주의는 한 번 | 끊임없이 울리는 것은 위험뿐이어야 알람 피로가 줄어든다 |
| 확인 기한 | `ack_within_ms`: 받은 때부터의 길이(1 ~ 10분). 절대 시각이 아니다 | EC2 와 워치의 시계 차이에 기한이 흔들리지 않게 한다. 격상 자체는 EC2 가 한다(부록 C.6) |
| 기한 시계 | 받은 시각과 기한 경과는 단조 시계(`SystemClock.elapsedRealtime`)로 잰다. 확인 시각(화면·ack)만 벽시계(UTC ms)다 | NTP 보정으로 벽시계가 뛰어도 기한이 갑자기 지나거나 늘어나지 않게 한다. 에뮬레이터에서 부팅 직후 시계 보정으로 알림이 바로 "기한 지남" 이 되는 것을 겪고 바꿨다 |
| 기한이 지난 뒤 | 진동만 멈추고 화면과 확인 단추는 남긴다 | 격상 뒤에도 작업자는 확인할 수 있어야 한다. 확인은 해소가 아니다(FR-9) |
| 알림이 여러 개 | 급한 등급이 먼저, 같으면 나중에 받은 것이 먼저. 나머지는 "+N" | 작은 화면에는 하나만 보인다 |
| 같은 event_id 가 다시 옴 | 확인 대기 중이면 내용만 바꾸고 기한 기준은 지킨다 / 기한이 지났으면 새로 받은 것 / 확인한 것은 내용만 바꾸고 다시 울리지 않는다 | 서버가 되풀이해 보내도 기한이 밀려 격상이 늦어지지 않게 한다 |
| 한 단어 | 1~8자. 글자 크기는 화면 폭 × 0.7 ÷ 글자 수(36~20sp) | 작은 화면에서 잘리지 않게(FR-45 "한 단어"). 20sp 이상은 사용자 글꼴 설정으로 커지지 않는 Wear 규칙을 따른다 |
| 방향 | FRONT·BACK·LEFT·RIGHT(↑ ↓ ← →), 없을 수 있다 | FR-45 "방향". 어느 쪽이 기준인지(작업자가 보는 쪽인지)는 -334 계약에서 정한다 |
| 칸 이름 | `event_id, severity, vibration, direction, word, sent_at_ms, ack_within_ms, needs_check` | -334 계약이 없어 정한 초안. 계약이 나오면 이름만 맞춘다. 인텐트 extra 도 같은 이름을 쓴다 |
| 알림 보관 | 지금은 화면(Activity)이 들고 있다 | EC2 연결 서비스(-337)가 생기면 보관을 서비스로 옮긴다. 화면은 `AlertActivity.intentFor` 로 부르기만 하면 된다 |
| 확인 단추 | 화면 아래 25% 를 차지하는 반달 단추(너비 76%, 어두운 회색 `#2E2E2E` 바탕에 흰 글자). 한 번 탭하면 확인이다 | 장갑 낀 손가락으로도 누르게 크게, 길게 누르기·슬라이드는 쓰지 않는다(취소할 수 없는 행동이 아니다). Wear 의 가장자리 단추(EdgeButton)는 목록이 끝에 닿아야 커져서 짧은 알림 화면에서는 작은 알약으로 남아 쓰지 않았고, 같은 모양을 직접 그렸다(에뮬레이터에서 확인) |
| 확인 보내기 | `AlertAcker` 인터페이스. 지금은 `LogAlertAcker`(logcat `SimaiWatchAck`) | 서버가 없다. -337 이 실제 전송으로 바꾼다 |
| 가짜 알림 | debug 빌드에만 `DebugAlertActivity`(DUMP 권한, adb shell 만, `taskAffinity` 를 비움) | release 앱에 시험 입구가 남지 않게 한다. 작업 소속을 비우지 않으면 시스템이 알림 화면이 떠 있는 작업으로 입구를 끼워 넣다가 새 알림을 전달하지 않았다 |

### 화면 디자인 (안 A 큰 아이콘형, 한눈에 읽기)

디자인 조사(Wear OS 공식 가이드, 안전 경보·진동 연구, 워치 경고 화면 사례)를 바탕으로 정했다. 위에서 아래로 읽는 순서는 큰 아이콘 → 등급 글자 → 큰 한 단어(방향 화살표가 붙는다)다.

| 항목 | 정한 값 | 근거 |
|---|---|---|
| 바탕 | 순수 검정. 등급색은 링·아이콘·등급 글자에만 쓴다 | Wear OS 는 검정 바탕이 필수이고, 큰 단색 면은 상시표시·OLED 번인 규칙과 어긋난다 |
| 등급색 | 위험 `#FF4245`(검정 위 6.1:1), 경고 `#FF9230`(9.4:1), 주의 `#FFD600`(14.9:1) | 검정 위 대비가 모두 4.5:1 이상. Apple 다크 시스템색 |
| 아이콘 | 화면 폭의 34% 크기. 위험 채운 팔각형, 경고 삼각형 윤곽, 주의 원 윤곽, 모두 느낌표. 옅은 원 바탕 | 남성 약 8% 가 적록색약이라 색만으로 구분하지 않는다. 모양과 글자(위험·경고·주의), 진동 패턴을 함께 쓴다 |
| 남은 시간 링 | 가장자리 링이 확인 기한까지 줄어든다. 12시 방향 왼쪽 아래(7시)에서 시계 방향 300도, 아래 60도는 비워 확인 단추 자리를 둔다 | 기한을 눈으로 보이게 한다. 기한이 지나면 링이 한 바퀴 차고 "기한 지남 +0:12" 로 바뀐다 |
| 글자 | 등급 글자(위험·경고·주의)와 "확인 필요" 는 등급색 한 줄(화면 폭의 6.5%), 한 단어는 흰색 굵게(36~20sp, 작은 화면은 상한이 화면 폭 × 0.16) | 한 화면에 정보 4개 이하, 1~2초 안에 읽히게 |
| 방향 화살표 | 서버가 방향을 줄 때만 한 단어 줄에 붙는다(오른쪽은 단어 뒤 "멈춤 →", 나머지는 단어 앞 "← 멈춤"). 방향이 없으면 단어만 나온다. 글자 크기는 화살표를 포함한 줄 길이로 정한다 | 명세 FR-45 "방향·한 단어" 와 -334 필드에 있어 넣었다. 방향의 기준(피할 쪽인지 위험 쪽인지)은 -334 에서 정해야 한다. 따로 줄을 쓰지 않아 화면이 단순하다 |
| 크기 | 모든 크기는 화면 폭 대비 비율이다(192dp ~ 227dp 둥근 화면에서 같은 모양) | 둥근 화면 크기가 기기마다 다르다 |
| "+N" | 아이콘 오른쪽 위의 흰 원에 숫자 | 다른 확인 대기 알림이 있다는 것만 알린다 |
| 움직임 | 위험 아이콘만 1.0 ~ 1.06 배로 1.2초 주기 맥박. 글자는 깜빡이지 않는다. 사용자가 애니메이션을 껐으면(동작 줄이기) 멈춘다 | 초당 3회 미만. 깜빡임은 미확인 경보에만 쓴다 |
| 상단 시계 | 알림 화면에는 두지 않는다 | 링과 겹치고 알림 판독을 방해한다. 대기 화면에는 있다 |
| 대기 화면 | 큰 글자로 "연결 안 됨"(설정이 없으면 노랑 "설정 안 됨"), 마지막 알림 시각. EC2 주소·토큰 설정 여부·버전은 아래로 스크롤해야 나온다 | 작업자는 연결 상태와 마지막 알림만 보면 된다. 개발용 값은 숨긴다 |

### 에뮬레이터 (2026-10-31, Wear OS 5.1 API 35 큰 원형, Windows WHPX, debug 가짜 알림)

- 위험·경고·주의가 각각 `DANGER_LONG`(되풀이)·`CAUTION_DOUBLE`·`CAUTION_WEAK` 로 울린다(`adb logcat -s SimaiWatchVibe`, 진동기 덤프의 세기·길이도 일치)
- 위험→경고→주의 순으로 겹쳐 보내면 화면은 가장 급한 알림이고 "+N" 이 센다. 확인하면 다음 알림이 뜨고 진동 패턴이 바뀐다
- 마지막 알림을 확인하면 "확인함 시각" 이 뜨고 2초 뒤 닫힌다. 확인 기록이 `SimaiWatchAck` 에 남는다
- 기한이 지나면(4초 시험) "기한 지남" 이 붙고 진동이 멈추며 확인 단추는 그대로다
- 화면이 꺼진 상태(Dozing)에서 알림이 오면 화면이 켜진다(Awake)
- 검정 바탕에 링·아이콘·큰 한 단어·방향·반달 확인 단추가 한 화면에 들어간다. 5자 단어("안전지대로")도 한 줄에 들어간다(스크린샷 확인)
- 기한이 지나면 링이 한 바퀴 차고 "기한 지남 +0:09" 가 된다
- 첫 화면은 소프트웨어 렌더링 에뮬레이터라 느리다(첫 알림 뒤 몇 초). 실기기 속도는 아래 남은 일에서 확인한다
