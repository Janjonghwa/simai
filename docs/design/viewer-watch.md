S15P31A101-342. 명세 부록 C.6(채널 상태 BOUND·UNBOUND·LOST, 격상), FR-117(아바타 위 채널 아이콘, 추적 인원 vs 활성 워치 수,
착용 의무가 있을 때 "연결된 워치 없음"), 14장(조회는 열람 이상), 11.4-5(이름 없음). 서버는 -336(연결·`viewer_health.watches`),
-338(배정 API·`/topic/watch` `watch_escalation`), -340(움직임 대조 배정). 시연 장면 3(부록 E: B 의 워치가 보호구 경보에 진동)에서

## 화면

- **워치 패널**: "추적 N명 · 활성 워치 M대 / 등록 R". 워치마다 연결·끊김, 배터리, 배정된 World ID(움직임 대조면 '(자동)').
  3D 에서 사람을 고르면 그 사람의 채널 상태(연결됨·워치 끊김·연결된 워치 없음)를 보이고, 관리자는 워치를 골라 "이 사람에게 잇기",
  배정된 워치는 "풀기". 서버 오류 문구(없는 워치·빈 World ID·동시 배정 409)를 그대로 보인다. 관리자 편집 모드 동안은 숨긴다.
- **아바타 이름표**: 배정된 사람의 이름표 끝에 "워치 watch-01"(연결) 또는 "워치 끊김 watch-01"(끊김)을 붙이고, 그 사람의 이름표는
  늘 보인다. 배정 없는 사람(UNBOUND)에는 붙이지 않는다.
- **격상 알림**: `watch_escalation` 이 오면 상단 알림 영역에 "워치 진동 뒤 확인 없음(또는 보내지 못함) · 기기 · World ID · 등급"을
  1분 보인다(최대 3개, 닫기). 이벤트 상태는 바꾸지 않는다(워치 ACK·격상은 운영자 확인이 아니다).

## 명세가 비워 둔 곳에서 정한 것

| 항목 | 정한 값 | 근거 |
|---|---|---|
| 연결의 정본 | `viewer_health.watches.items[].link`(1초마다), 배정은 REST 를 3초마다(보이는 탭만) | health 에는 배정이 없고(1.2.0), 대조 배정은 2초마다 바뀔 수 있다 |
| 3D 다시 그리기 | 이름표 글은 '기기=연결' 문자열만 구독해 연결·배정이 실제로 바뀔 때만 새로 만든다 | health 는 1초마다 새 객체라 통째로 구독하면 3D 호스트가 1초마다 다시 그려진다(리뷰) |
| 잇기 안전 | 고른 사람의 지금 워치가 기본이고 그 워치로는 잇기를 막는다. 다른 사람의 워치를 고르면 '옮긴다'고 알린다 | 서버는 잇기 때 그 워치·World ID 의 옛 배정을 말없이 끝낸다 |
| 활성 워치 수 | `watches.connected`(지금 연결된 워치) | -336 설계: "활성 워치 수는 connected" |
| 이름표 글 | BOUND "워치 기기ID", LOST "워치 끊김 기기ID", UNBOUND 없음 | 아이콘 대신 기존 이름표(sprite)에 글로 붙인다. DOM 이름표는 StrictMode 에서 비는 문제가 있어 뷰어가 쓰지 않는다 |
| "미착용" | 쓰지 않는다. 고른 사람에게 배정이 없으면 "연결된 워치 없음" | FR-117. 착용 의무 정보가 아직 없어 고른 사람에게만 보인다 |
| 배정 조회 권한 | 열람 이상 | 14장 조회는 열람 이상. 익명 World ID·기기 ID 만 있다. 이름표를 모든 관제 계정이 봐야 한다 |
| 격상 알림 | 1분, 최대 3개, 같은 알림은 한 번 | 서버가 한 알림에 한 번만 보낸다. 오래 쌓지 않는다 |
| `/topic/watch` | 3D 뷰어 Source 로 넘기지 않는다 | 뷰어 계약 입력이 아니라 넘기면 계약 위반으로 센다 |
| 사람 이름 | 다루지 않는다 | 11.4-5. 시연에서 "B 의 워치 = watch-01" 은 발표자만 안다 |

## 남은 일

- 완료 조건 "워치 1대 연결·끊김에서 아이콘·수치가 바뀌는 화면 기록": 실제 워치와 운영 EC2 로 녹화해야 한다.
- 착용 의무(구역·작업별)가 생기면 그 사람들의 이름표에 "연결된 워치 없음"을 늘 보인다.
- 화면에 없는 사람(가려짐)에게 이으려면 World ID 목록 입력이 필요하다(지금은 3D 선택만).
