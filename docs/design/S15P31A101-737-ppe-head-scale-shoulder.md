# S15P31A101-737 PPE 머리 폭 하한을 어깨 폭 기준으로 두기

관련 명세: 5.5(사람과의 연결: 안전모는 머리 영역과 겹쳐야 그 사람의 근거). 선행: -491(PPE 판정), -729(UNKNOWN 분해·빈 칸 계측). 명세 반영: 필요 없음(아래 "명세와의 관계").

## 왜 하나 (실측)

-729 에서 PPE 쪽 UNKNOWN 원인 중 가장 큰 것이 표본 사유 `NO_DETECTION` 이었다. 이를 실제 프레임으로 다시 쟀다.

### 측정 조건

- 녹화: 14차 로비(2026-11-12) mp4 4대. 녹화 39분(2340 s) 이후.
- 방식: 카메라 한 대씩 2 Hz 로 뽑아 판정했다. 운영 가중치(포즈 `yolo26x-pose` 1280 half, PPE T1-v4 640 FP32 conf 0.5)와 운영 연결 코드 `associate_frame` 을 그대로 썼다.
- 사람 후보는 포즈 점수 0.5 이상만 셌다.
- 장비: 노트북 RTX 4050. 영상·프레임은 저장하지 않았다.
- mp4 의 프레임 시각이 40 ms 명목값이라 카메라 사이 연결(Tier 0)·누적 창은 재현하지 않았다.

### 1차 분포 (4대 합계 사람×프레임 38,167건)

| 사유 | 안전모 |
|---|---|
| 결정(미착용·착용) | 45.2% · 10.1% |
| 검출 없음(`NO_DETECTION`) | 26.7% |
| 영역 불선명(`REGION_NOT_CLEAR`) | 11.8% |
| 영역 안 보임 | 4.1% |
| 겹침 | 2.2% |

### 표본 확대 (시드 7290)

- 대상: 크게 잘 보이는데(키 300 px 이상, 포즈 점수 0.85 이상) 검출 없음인 사람 200명.
- 대조: 같은 조건에서 정상 연결된 사람 100명.
- 같은 프레임을 다시 검출해 300명 모두 재현했다.

| | 대상(검출 없음) | 대조(정상 연결) |
|---|---|---|
| 머리 폭 / 키(중앙값) | 0.07 | 0.11 |
| 머리 폭 / 어깨 폭(중앙값) | 0.45 | 0.86 |
| 머리에 걸친 PPE 후보 | 180/200(미착용 151, 착용 29) | 100/100 |
| 후보가 머리 영역 안에 든 비율(중앙값, 연결 기준 0.6) | 0.43(180명 전원 0.6 미만) | 0.87 |

검출기가 아무것도 내지 않은 경우는 200명 중 20명뿐이었다. 나머지는 옆·뒷모습에서 눈·귀 간격이 좁게 잡혀 머리 영역이 실제 머리보다 작았다. 그래서 상자가 "부분 겹침"으로 분류됐고, 연결 코드의 마지막 분기에서 `NO_DETECTION` 이 됐다.

## 결정

- 두 어깨(COCO 5·6)가 keypoint 신뢰도 기준을 넘고 화면 안에 있으면, 머리 폭 하한을 `어깨 폭 × head_min_scale_shoulder_ratio(0.6)` 으로 둔다. 어깨가 하나라도 없으면 지금 규칙 그대로다. 0 이면 끈다.
- 넓어지는 것은 머리 영역(상자 위치·크기)과 검출 폭 비 검사 기준이다. 선명한 머리 판단(미착용 근거로 쓸 수 있는지)은 하한 전의, 눈·귀로 잰 폭으로 한다. 어깨 하한 때문에 작은 얼굴이 "선명"해져 미착용 근거가 늘지 않게 하려는 것이다.
- `policy_version` 을 `ppe-policy-0.5.0` 에서 `ppe-policy-0.6.0` 으로 올린다. `ppe_state` 스키마, 사유 코드, 누적 창은 바꾸지 않는다.

## 정한 수치와 근거

같은 300명에 실제 구현 코드를 넣어 이전 규칙(비율 0)과 비교했다. 실험 때 측정과 300명 모두 같은 판정이었다.

| 비율 k | 대상 판정 회복 | 대조 유지 | 착용↔미착용 뒤집힘 |
|---|---|---|---|
| 0.4 | 10/200 | 99/100 | 0 |
| 0.5 | 55/200 | 99/100 | 0 |
| **0.6(채택)** | **80/200**(미착용 63, 착용 17) + 영역 불선명 19, 겹침 3 | 99/100(1명 미착용 → 겹침) | 0 |

- **직접 확인**: 회복된 80명 중 24명(카메라당 6명, 착용 8·미착용 16)을 머리 부분만 잘라 사람이 눈으로 확인했다. 24/24 가 실제와 같았다. 정확도 95% 신뢰 하한(한쪽, 정확 이항)은 약 88% 다.
- **같은 프레임의 다른 사람**: 대상 프레임에서 검출 없음 → 판정 18, 겹침으로 바뀜 4(그중 1건은 다른 사람의 착용 판정이 함께 겹침이 됨). 대조 프레임에서 검출 없음 → 판정 14, 검출 없음 → 겹침 1.
- **0.6 을 고른 이유**: 대조 결과가 0.4~0.6 에서 같았고, 0.6 이 회복이 가장 컸다. 대조의 머리 폭/어깨 폭 하위 25% 가 0.50 이라, 0.6 은 정상인 사람 머리 폭과 크게 어긋나지 않는다. 더 키우면 옆 사람 머리 상자를 끌어올 위험이 커지는데, 이는 겹침(SHARED) 규칙이 먼저 막는다.

## 명세와의 관계

- 명세 5.5 는 "머리(눈·귀) 영역과 겹쳐야 한다"고만 정한다. 머리 폭 산정과 확장 배수(`head_*`)는 설계 초안의 제안값(`ai/src/simai_ai/ppe/config.py` 머리말)이라 명세 변경은 필요 없다.
- 머리 영역의 중심은 여전히 눈·귀로 잡는다. 어깨는 크기 하한에만 쓴다.

## 버린 대안

- **연결 기준 cov 0.6 을 낮추기**: 머리 위치와 무관하게 모든 사람에게 느슨해진다. 손에 든 안전모, 옆 사람 머리를 붙일 위험이 크다.
- **사람 상자 높이 기반 하한(예: 키 × 0.1)**: 어깨가 안 보이는 사람도 덮지만, Tier 0 가 공유하는 사람 상자를 PPE 관측에 새로 실어야 한다. 앉거나 숙인 자세에서 키가 머리 크기와 덜 맞는다. 필요하면 후속으로 한다.
- **선명한 머리 판단도 하한 뒤 폭으로 하기**: 실측 300명에서는 결과가 같았다. 하지만 작은 얼굴이 미착용 근거가 되는 쪽으로 기울어서 택하지 않았다.

## 잔여 위험

- 한 세션(14차 로비, 39분 이후), 카메라 한 대씩 판정한 결과다. 카메라를 합친 누적에서 안전모 UNKNOWN 이 얼마나 줄지, 미착용 경보가 얼마나 늘지는 현장·재생에서 확인해야 한다.
- 회복분은 미착용이 대부분(63/80)이다. 이 녹화의 실제 착용 비율을 반영한 것이지만, 미착용 경보가 늘어나는 방향의 변경이다. 직접 확인 24/24 는 표본이 작다.
- 어깨가 화면 밖이거나 가려진 사람에게는 효과가 없다.
