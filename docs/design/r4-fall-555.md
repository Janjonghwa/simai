# R4 낙상 의심 임계 완화 (S15P31A101-555)

## 결정과 근거

2026-11-09 Lead 승인으로 명세 7.2의 R4 v1 초기값을 변경했다. 머리 하강은 2초 창 0.5m 이상, 낮은 자세는 검증되거나 유지된 지지면 기준 0.8m 이하에서 1.5초 유지, 해소 경계는 1.0m 초과다. 후속 창은 3초, 급하강 직후 관측 상실 창은 1.5초다. 접지 이력이 전혀 없을 때 머리 하강량의 발생·해소 기준은 각각 0.8m·0.6m다. CRITICAL 및 확인 필요 처리, 접지 미확인 시 Z를 지어내지 않는 원칙은 유지한다.

12차 DB 발췌에서 같은 ID의 OBSERVED 머리 값 1.591→0.669m가 1.207초에 내려갔고 중간에 추적 관측이 끊겼다. 이전 1초 창은 두 표본을 함께 보지 못했다. 완화 기준의 발췌 재생에서는 급하강 후보와 관측 상실 경로가 발생한다. DB는 모든 Tier 0 tick과 `t_last_valid`를 보존한 입력이 아니고 해당 인물이 연출을 했는지 확인되지 않아 실시간 검출 성능 근거는 아니다.

## 시험과 잔여 위험

`ai/tests/risk/test_r4_fall_suspect.py`는 접지가 확인되고 관측이 지속되는 조건에서 바닥 앉기(0.9m), 줍기(1.0m), 웅크림(1.1m), 빠른 앉기(0.45m 하강), 0.45m 단상 보행의 오경보 부재를 시험한다. 0.45m 단상에서 1·2초에 내려가 바닥 기준 머리 0.4·0.6·0.75m로 유지하는 시연과 후보 직후 관측 상실도 시험한다. 공통 벡터와 G6 SIM 시험은 변경된 판정과 생명주기를 기록한다.

완화에 따른 **오경보가 존재한다**. 빠르게 앉은 뒤 관측이 끊기거나 이어서 눕는 동작, 또는 접지 이력이 전혀 없는 상태에서 머리 1.72→0.9m로 앉는 동작은 CRITICAL 발생이 가능하다. 마지막 경우 `Z_UNKNOWN`을 붙인다. 기본 2주기 SIM에서 낙상 8/8 검출, 의도적 눕기 오경보 2건으로 SIM 상태는 FAILED다. 이는 실영상 제품 성능이나 G6 합격 판정이 아니다. 임계를 더 바꾸거나 상실 판정의 안전 의미를 약화하는 대안은 이번 Lead 결정에 포함하지 않았다.

13차에는 연출 시각·World ID와 ID 변경, 실제 접지 표면, Tier 0 매 tick 머리·접지 유효성과 후보·관측 상실을 함께 기록하여 시연 검출과 정상 동작 오경보를 현장에서 검증한다. 기록·시험 세부 결과는 worktree의 `.agy/notes.md`에 있다.
