# S15P31A101-823 ④ 작업 관리 화면 UX 설계 메모

## 정한 수치·배치
- **달력 (`CalendarCell`, `WorkCalendar`, `calendarMath`)**:
  - 오늘 칸은 B안(`TODAY_CELL_STYLE = 'B'`)으로 칸 전체를 파란 단추(`#2F66E8`, 흰 글자)로 채우고 「오늘」 배지를 두지 않는다.
  - 지난 날 칸과 월간 요약은 `HIGH` + `CAUTION`을 「주의」로 합산해 「위험 N · 주의 M」 한 줄(폭 부족 시 줄바꿈)로 보인다. 호버 힌트(`히스토리 보기`)는 `opacity` 오버레이로 두어 이벤트 수 줄의 폭을 뺏지 않는다.
- **TBM 빈 양식 (`ReportView`, `paperTables`, `ReportEditDialog`, `PaperTasksField`)**:
  - 작업내용이 비어 있을 때 나머지 셀은 어두운 빗금으로 낮추고 작업내용 칸만 흰 바탕 + 파란 테두리(`ring-2 ring-blue-600`)와 중앙의 큰 「+ 작업내용 선택」으로 강조한다.
  - 초안 전 모달 제목은 「작업내용 선택」, 초안 후 전체 편집 모달 제목은 「TBM 보고서 편집」을 유지한다.
- **작업 전 확인 · 서명 (`PreflightStage`, `LayoutPreview`, `SignDialog`, `ReportPanel`)**:
  - 좌우 반반 배치: 왼쪽 「TBM 보고서」 + 우측 끝 「출력」(`variant="action"`, `size="action"`), 오른쪽 「현장 3D 맵」 + 「위험 N · 주의 M」. 서명 카드·구역 목록·워치 카드는 제거했다.
  - 서명 0명이면 주 단추 「서명하기」, 1명 이상이면 「서명 추가」 + 「작업 시작」. 서명 창은 우측 상단 `×`, 빈 칸 안내, 「지우기 / 저장 후 다음 사람 / 저장 후 완료(또는 완료)」, 재오픈 시 서명자 목록과 삭제를 제공한다.
- **작업 진행 중 · 종료 뒤 (`RunStage`, `EventListCard`, `AppliedStatusCard`, `WorkActionLayer`)**:
  - 진행 중 화면은 좌우 반반이며 왼쪽은 `fit`으로 TBM 전체가 한 화면에 보이고 「크게 보기」·「출력」 단추를 두지 않는다. 오른쪽은 타이머, `IncidentCard`를 재사용한 「경보 기록」(최신순), 접이식 한 줄 「✓ 관제 적용됨 · 구역 N · 카메라 live/total」(`pb-[76px]`로 하단 큰 「작업 종료」 단추가 가리지 않게 확보).
  - 종료 뒤에는 「한 번 더 실행」 단추를 제거하고, 단추 옆과 종료 미팅 셀에 움직이는 점(`LoadingDots`)으로 「종료 미팅 작성 중」을 보인다. 완료 시 종료 미팅 셀로 스크롤해 2.5초간 `ring-2 ring-primary`로 강조하고 「보고서 제출」을 켠다.
- **지난 날 다시 보기 (`PastDayPage`, `PastReportPanel`, `Timeline`, `WorkLists`, `ReplayVideoWall`)**:
  - 타임라인은 영상 아래 배치, 핀은 `▲`(위험) / `!`(주의)이며 호버 시 툴팁 없이 아이콘만 확대(`scale-125`)한다.
  - 핀 배치는 트랙 폭에 따라 버튼 폭(`8~20px`)을 계산해 좌→우, 우→좌 두 패스로 인접 핀 간격을 버튼 폭 이상 벌리고 `[half, width - half]` 안으로 고정한다. 썸(`THUMB`)과 줄무늬(`GapMarks`)에 `pointer-events-none`을 주고 핀을 `z-20`에 올려 클릭 가로막힘을 없앴으며, 슬라이더 막대에서 핀 중심 ±12px 이내 클릭도 해당 이벤트로 점프(`raisedAt - 3000ms`에서 재생, 이벤트 로그 강조·스크롤)한다.
  - 카메라 시각 배지는 `|videoTime - playhead| > 1000ms`일 때만 표시한다.
  - 오른쪽 열은 탭 없이 「이벤트 로그 · N건」(×N 제거)과 「TBM 보고서」(머리 「출력」, 썸네일, 하단 「크게 보기」)를 함께 배치한다.

## 버린 대안
- **타임라인 핀 `calc(percent + offset)` 상대 이동**: 같은 구간에 경보가 몰릴 때 인접 버튼끼리 겹치거나 시작 시각(`09:00`) 글자 위로 삐져나가 클릭 가로막힘이 발생해, 트랙 폭 기반 2-패스 절대 픽셀 배치로 교체했다.
- **진행 중 화면 TBM 스크롤 방식**: `fit` 없이 전체 크기로 두면 세로 스크롤이 길어지고 우측 카드와 균형이 깨져, 좌측 반 화면에 A4 전체가 한눈에 들어오는 `fit` + `withPrint={false}`를 채택했다.
- **공통 컴포넌트(`DashPanel`) 수정**: 다른 티켓 범위 충돌을 피하기 위해 `DashPanel.tsx`는 건드리지 않고, `PastDayPage` 래퍼(`*:flex-1`)로 TBM 카드 높이를 확보하고 `EventLog` 제목으로 「이벤트 로그 · N건」을 표현했다.
