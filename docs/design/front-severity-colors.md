# 구역 심각도를 위험·경고로 줄이고 심각도 색·구역 윤곽선을 바꾼다 (S15P31A101-432)

위험 구역의 심각도를 위험(`CRITICAL`)과 경고(`HIGH`) 둘로 줄이고, 앱 전체의 심각도 색을 위험 빨강·경고 주황·주의 노랑으로 맞추며,
실시간 관제의 구역 윤곽선을 그 구역의 심각도 색으로 늘 보이게 한다. 사용자 결정(2026-11-03)이고, 같은 방향의 명세 개정은
S15P31A101-426 에서 한다. 서버로 가는 값(`CRITICAL`·`HIGH`)은 그대로다.

## 버린 대안

- **3D 에서 CSS 변수를 런타임에 읽기**: 시험 환경에서 비어 대체값을 다시 하드코딩하게 되고, 테마를 바꿀 때 재질을 다시 읽어야 한다. 색표 값을 토큰과 같게 두고 시험으로 맞췄다.
- **깊이 검사만 끄기**: 윤곽선이 책상·벽 앞에 있는 것처럼 보여 앞뒤 구분이 사라진다. 깊이 검사 선은 그대로 두고 가려진 부분만 흐리게 덧그렸다.
- **응답 검사에서 주의·안내를 거부**: 기존 구역이 사라진다.
- **기존 주의·안내 값을 몰래 경고로 바꿔 저장**: 사용자가 모르는 사이 심각도가 바뀐다. 다시 고르게 한다.

## 남은 위험과 넘긴 일

- 서버가 구역 심각도를 아직 네 값으로 받는다(`ZoneRepository.SEVERITIES`·DB `CHECK`). 위험·경고 둘로 줄이고 저장된 주의·안내 구역을 옮기는 일은 서버 담당(곽나혁 님)과 맞춰야 한다.
- 위험이 걸린 구역은 윤곽선과 위험 강조(바깥 상자·이중선)가 같은 색이다. 강조는 이중선·바깥 상자·이름표로 구분되지만 윤곽선과 겹쳐 덜 두드러질 수 있다.
- 다각형 구역(PRISM·FOOTPRINT)은 진행 중 위험이 걸리면 윤곽선이 위험 모양(색·이중선)으로 바뀐다. 상자 구역과 달리 위험을 따로 보이는 바깥 상자가 없어서, 위험을 윤곽선이 나르던 기존 동작을 그대로 두었다. 지금 실시간 관제의 구역은 모두 상자라 영향이 없다.
- 공중 구역의 바닥 안내선은 가린 부분 덧그리기가 없다(보조선이라 흐리게 이어 그릴 필요가 없다고 보았다).
- 구역 위험이 아닌 곳의 빨강·노랑(설치·보정 상태, TBM 평면, 오류 문구, CCTV LIVE 점)은 바꾸지 않았다.
- 명세·요구사항 개정과 계약(`risk_plan_request` 의 구역 심각도)은 S15P31A101-426 몫이다.
