# S15P31A101-827 외형 표본 주기

명세 3.2·5.2·5.6의 Tier 0 우선과 표시 전용 외형을 유지한다. 판정 루프가 마지막으로 적용한 `ActiveConfig.work_in_progress`를 기존 `tier0.live` 원자적 갱신에 싣고 아바타 외형 작업자가 읽는다. 별도 서버 요청이나 워커 대여가 필요 없고 판정값은 바꾸지 않는다. 아직 구성이 없거나 파일이 없고 오래되거나 형식이 틀리면 모름이다. 표시 파일은 기본 5초마다 갱신하므로 전환 반영이 지연될 수 있다. 부하 접수 관문은 이 신호와 독립적으로 먼저 적용된다.

작업 전은 500 ms, 작업 중과 모름은 설정된 기본 2000 ms다. 작업 중 성공적으로 마친 표본마다 유효 UV 면적 중 가중치가 있는 텍셀의 증가분을 비교해 0.5%p 미만이 연속 5회면 다음 간격을 6000 ms로 늘린다. 0.5%p 이상 증가하거나 작업 상태·ID 차수가 바뀌면 연속 횟수를 초기화한다. 기존 설정 `SIMAI_AVATAR_TEXTURE_INTERVAL_MS`는 작업 중 기본 간격에 계속 적용된다. 발행 주기와 화면은 바꾸지 않는다.

다음 GPU 세션에서 같은 카메라·인원·움직임으로 작업 전/중 전환과 포화 이후 추가 회전을 재현한다. 외형 누적 로그의 시각·accepted 수와 자산의 관측 비율 및 첫 유효 외형까지 걸린 시간을 비교하고, Tier 0 판정·검출 p95, 지연 초과 및 게이트 중단 횟수도 함께 기록한다. 상태 전환은 표시 파일 갱신 지연을 포함해 확인하고 GPU 세션을 마친 뒤 인스턴스를 중지한다. 표본 면적 증가가 낮더라도 이후 새 시점은 최대 6초 뒤에야 반영될 수 있다.
