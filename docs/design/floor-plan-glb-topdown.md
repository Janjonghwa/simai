# Scene GLB 평면도

명세 3.1·4.1·11.7·12.5·12.6. 구현은 `front/apps/admin/src/features/viewer3d/scene/scenePlan.ts` 와 `features/plan/`, 시험은 `src/__tests__/features/` 에 둔다.

뷰어가 읽은 Scene 을 별도 WebGL 문맥에서 직교 투영한다. 바닥 위 1.6 m 자름은 시제품의 가구 표현을 따르고, 긴 변 768 px 는 작은 지도에서 세부를 확보하기 위한 값이다. 북쪽(+Y)을 위로 두어 World 좌표와 일치시킨다. 결과는 버전별 메모리 캐시에 저장하며 렌더러는 즉시 해제한다. 워커 BEV 와 3D 기본 시점의 45도 마름모는 별도 작업과 좌표 혼동 때문에 채택하지 않았다.

표시 전용이며 구역 편집의 계산은 변경하지 않는다. GLB 의 빈 공간이나 위쪽을 향하지 않은 면, WebGL 실패 및 버전별 이미지의 메모리 사용이 잔여 위험이다.
