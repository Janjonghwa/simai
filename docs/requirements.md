# simai 요구사항 명세서 v1.3

2026-10-17 · A101 · 기준: 기획서 v1.3 (`docs/spec/`)

simai는 고정 카메라 4대로 작업 공간의 사람·장비·정적 구조를 하나의 미터 좌표 3D 디지털 트윈에 올리고, 위험을 근거와 함께 판정해 현장 담당자에게 전달하는 예방형 안전 관제 플랫폼이다.

**이 문서의 규칙**

- 기획서(`docs/spec/`)에서 파생한 요구사항 표다. 세부 기준·근거는 기획서가 정본이다.
- **ID 는 고정한다.** 기능 요구사항 `FR-n`, 비기능 요구사항 `NFR-n`. 삭제한 번호는 다시 쓰지 않고 행을 "폐기(버전)"로 남긴다. 새 요구사항은 끝 번호 다음에 붙인다.
- **진행 상태는 적지 않는다.** 진행은 Jira 에서 본다. Jira 스토리 본문에 관련 ID(`요구사항: FR-60, FR-61`)를 적어 추적한다.
- **갱신 시점:** 기획서가 바뀔 때마다가 아니라 마일스톤(M1·M2·M3)과 제출 전에 몰아서 맞춘다. 기획서 MR 이 요구사항에 영향을 주면 MR 본문에 `요구사항 FR-n 갱신 필요` 를 적어 둔다.
