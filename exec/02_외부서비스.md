# simai 외부 서비스

코드·배포 설정에서 찾은 외부 API·SDK·서비스 목록이다. 키 값은 플레이스홀더로만 적는다.
소셜 로그인, 결제, 지도, 메일, FCM 같은 푸시 서비스는 쓰지 않는다. 워치 알림은 자체 WebSocket(I4 `/ws/watch`)으로 보내고, 로그인은 자체 계정과 JWT 로 한다.

| # | 서비스 | 사용 목적 | 필수 여부 |
|---|---|---|---|
| 1 | AWS S3 | 녹화 영상·클립·3D 장면(glb)·반장 사진 저장, 임시 서명 주소 | 필수 (없으면 업로드·조회만 503) |
| 2 | RunPod | GPU 인스턴스(Tier 0·분석 워커) 켜기·끄기·자동 정지 | 필수 (실시간 관제) |
| 3 | AWS EC2 / Pricing / Secrets Manager (GPU) | 서울 리전 GPU 공급자 (예비) | 선택, 기본 꺼짐 |
| 4 | SSAFY GMS (OpenAI 호환 LLM) | TBM 보고서 자동 작성 | 선택 (없으면 보고서 생성만 실패) |
| 5 | 국가법령정보 공동활용 Open API | RAG 법령 조항 수집 | 선택 (시드 수집 때만) |
| 6 | 공공데이터포털 (KOSHA) | KOSHA GUIDE·재해사례 수집 | 미구현 (키 미발급) |
| 7 | Hugging Face Hub | GPU 이미지 모델 가중치 내려받기 | 필수 (GPU 이미지 빌드·부팅) |
| 8 | Let's Encrypt (certbot) | HTTPS 인증서 | 필수 |
| 9 | Cloudflare DNS / 호스팅.kr | 도메인 `simai.live` | 필수 |
| 10 | SSAFY GitLab + Jenkins Webhook | 소스·CI 트리거 | 필수 (CI/CD) |

## 1. AWS S3 (객체 저장소)

- **용도**: 비공개 버킷에 녹화 조각·이벤트 클립·Scene glTF/glb·사진을 둔다. 서버는 서명만 하고(Presigned URL 업로드 5분, 다운로드 5분) 파일 본문은 거치지 않는다.
- **사용 위치**: `server/build.gradle`(`software.amazon.awssdk:s3`), `server/src/main/resources/application.yaml` `simai.storage.*`, 게이트웨이 녹화 업로드(`gateway/ops/README.md`)
- **발급 절차**
  1. AWS 콘솔 → S3(https://s3.console.aws.amazon.com) → 버킷 생성. 리전 `ap-northeast-2`, **퍼블릭 액세스 모두 차단**.
  2. 브라우저가 서명 주소로 직접 PUT/GET 하므로 버킷 CORS 를 연다(근거: `docs/design/server-object-storage.md`):
     출처 `https://<DOMAIN>`·로컬 개발 `http://localhost:5173`·`http://localhost:5174`, 메서드 `GET`·`PUT`·`HEAD`, 헤더 `content-type`·`x-amz-checksum-sha256`, 노출 `ETag`.
     ```json
     [{"AllowedOrigins":["https://<DOMAIN>","http://localhost:5173","http://localhost:5174"],
       "AllowedMethods":["GET","PUT","HEAD"],
       "AllowedHeaders":["content-type","x-amz-checksum-sha256"],
       "ExposeHeaders":["ETag"]}]
     ```
  3. IAM(https://console.aws.amazon.com/iam) → 사용자 생성 → 이 버킷 객체에만 `s3:PutObject`·`s3:GetObject`·`s3:DeleteObject` 인라인 정책 → 액세스 키 발급.
     (SSAFY 제공 EC2 는 인스턴스 역할을 붙일 수 없어 정적 키를 쓴다.)
- **키·위치**: `/opt/simai/.env` → `SIMAI_STORAGE_BUCKET`, `SIMAI_STORAGE_REGION`, `SIMAI_STORAGE_ACCESS_KEY`, `SIMAI_STORAGE_SECRET_KEY`, `SIMAI_SCENE_DEFAULT_GLTF_KEY`(시연 기본 배경 객체 키)
- **특이사항**: 클립은 14일 뒤 서버 삭제 작업이 지운다(`simai.clip.*`). CCTV 원격 시청 송출은 월 80 GB 상한(`simai.cctv-remote.monthly-quota-bytes`). S3 요금은 저장량·요청·전송량 과금.

## 2. RunPod (GPU 클라우드)

- **용도**: Tier 0·분석 워커·vLLM 을 돌리는 GPU Pod. Pod 는 gateway 노트북에서 영상을 받고, 켜지면 부팅 비밀값으로 EC2 에 스스로 등록한다. EC2 서버는 RunPod API 로 유휴 자동 정지·재고 조회를 한다.
- **사용 위치**: `server/src/main/java/com/ssafy/simai/domain/gpu/provider/RunPodProvider.java`, `global/properties/GpuProperties.java`(API `https://api.runpod.io`), `deploy/README.md` 「RunPod 템플릿」「GPU 자동 부팅」
- **가입·준비**
  1. https://www.runpod.io 가입·로그인.
  2. **Billing** 에서 결제 수단(카드) 등록 후 크레딧 충전. On-Demand Pod 는 크레딧에서 초 단위로 차감된다.
  3. **팀 템플릿 접근**: 팀 템플릿을 만든 계정(또는 그 계정이 속한 RunPod Team)에서 써야 한다. 다른 계정이면 템플릿 소유자에게 Team 초대를 받거나 6.4 표 값으로 같은 템플릿을 만든다. TODO(확인 필요: 팀 템플릿 소유 계정·Team 이름)
  4. **Settings → API Keys** 에서 키를 만든다(EC2 서버의 자동 정지·재고 조회용).
  5. **Secrets** 에 `hf_token`, `simai_gpu_boot_secret`, `simai_tier0_tls_key` 를 등록한다(값과 템플릿 참조는 `01_포팅매뉴얼.md` 6.4 표).
- **실행 절차**: [01_포팅매뉴얼.md 4.4 RunPod GPU 서버 실행](./01_포팅매뉴얼.md#44-runpod-gpu-서버-실행-웹-콘솔)
- **키·위치**: `/opt/simai/.env` → `SIMAI_RUNPOD_API_KEY`, `SIMAI_GPU_BOOT_ID` / RunPod 템플릿 환경 변수·Secret(01 6.4)
- **특이사항**: On-Demand 로 띄우고 **사용 후 반드시 Terminate**(과금). 한 시점에 Pod 1대. 볼륨 미사용. 통합 이미지 전체 이름·다이제스트: TODO(확인 필요).

## 3. AWS EC2·Pricing·Secrets Manager (서울 GPU, 예비)

- **용도**: RunPod 대신 AWS 서울 GPU 인스턴스를 띄우는 공급자. 기본 꺼짐.
- **사용 위치**: `server/build.gradle`(`awssdk:ec2`, `awssdk:pricing`), `application.yaml` `simai.gpu.aws.*`, `docs/design/S15P31A101-703-aws-gpu-provider.md`
- **발급 절차**: IAM 사용자에 `ec2:RunInstances`·`TerminateInstances`·`Describe*`·`iam:PassRole`·`pricing:GetProducts` 만 허용 → 액세스 키. ECR 서울에 GPU 이미지 사본, Secrets Manager 에 `simai/gpu-boot` JSON(`SIMAI_GPU_BOOT_SECRET`, `SIMAI_TIER0_TLS_PRIVATE_KEY`, `HF_TOKEN`). 시작 템플릿·서브넷·보안 그룹은 관제 화면 「GPU 설정」.
- **키·위치**: `/opt/simai/.env` → `SIMAI_GPU_AWS_ENABLED`, `SIMAI_GPU_AWS_ACCESS_KEY_ID`, `SIMAI_GPU_AWS_SECRET_ACCESS_KEY`, `SIMAI_GPU_AWS_IMAGE`, `SIMAI_GPU_AWS_SECRET_ID`
- **특이사항**: GPU 인스턴스 시간당 과금, 스팟 선택 가능. GPU 할당량(vCPU quota) 신청이 필요할 수 있다.

## 4. SSAFY GMS — OpenAI 호환 LLM

- **용도**: TBM 보고서 초안 생성(Risk Engine `/v1/report/generate`). 외부 LLM 에는 텍스트만 보낸다(영상·얼굴 미전송).
- **사용 위치**: `ai/src/simai_ai/report/llm.py`(표준 urllib, Responses API 또는 Chat Completions), `ai/services/worker/tbm_report.py`, `deploy/ec2/compose.yaml` `risk-engine`
- **키·위치**: EC2 `/opt/simai/.env` (키 목록 `deploy/ec2/.env.example`) → `SIMAI_LLM_BASE_URL`, `SIMAI_LLM_MODEL`, `SIMAI_LLM_API_KEY`(`<GMS_API_KEY>`), `SIMAI_LLM_API_STYLE`, `SIMAI_LLM_TIMEOUT_S`, `SIMAI_LLM_TEMPERATURE`, `SIMAI_LLM_MAX_OUTPUT_TOKENS`. compose 가 `risk-engine` 컨테이너에 넣는다.

## 5. 국가법령정보 공동활용 Open API

- **용도**: 산업안전보건법령 조항 수집 → RAG 법령 그래프(pgvector).
- **사용 위치**: `ai/src/simai_ai/rag/law.py`, `ai/src/simai_ai/rag/graph/source_api.py`, `source_web.py`(`www.law.go.kr`), `deploy/ec2/load-legal-graph.sh`
- **발급 절차**: https://open.law.go.kr 가입 → OPEN API 신청 → **호출할 서버 IP 등록** → 인증값(OC, 보통 가입 이메일 ID) 확인.
- **키·위치**: 루트 `.env` → `SIMAI_LAW_API_OC`. 실행: `cd ai && uv run --env-file ../.env python -m simai_ai.rag.seed fetch`
- **특이사항**: 등록한 IP 에서만 응답한다. 무료.

## 7. Hugging Face Hub

- **용도**: GPU 통합 이미지 빌드·Pod 부팅 때 모델 가중치 받기(비공개 PPE 모델, 승인제 sam-3d-body 등).
- **사용 위치**: `deploy/weights.json`(PPE 항목 `ppe-t1-v4-all-e08`, 묶음 `ppe`), `deploy/scripts/simai_bootstrap.py`, `deploy/scripts/bake_weight.py`, `deploy/docker-bake.hcl` `unified`(BuildKit secret `hf_token`), `docs/data/weights.md`
- **비공개 PPE 모델 접근**
  1. **모델 저장소**: Hugging Face 에 로그인한 뒤 [SimAI PPE 모델 저장소](https://huggingface.co/simai-s15p31a101/simai-ppe-helmet-vest)를 연다.
  2. **권한 요청**: 저장소가 보이지 않으면 프로젝트 담당자에게 본인의 Hugging Face 사용자명을 전달하고 읽기 권한을 요청한다.
  3. **토큰 설정**: [Access Tokens](https://huggingface.co/settings/tokens) 에서 해당 저장소의 읽기 권한을 가진 `Fine-grained` 토큰을 발급한다. 토큰은 RunPod 에 `hf_token` 이라는 이름의 Secret 으로 저장하고, Pod 환경 변수 `HF_TOKEN` 의 값을 `{{ RUNPOD_SECRET_hf_token }}` 으로 설정한다.
  4. **가중치 확인**: SimAI GPU 컨테이너(Pod SSH 또는 RunPod 웹 터미널)에서 아래 명령을 실행한다. 종료 코드가 `0` 이면 PPE 가중치가 준비된 상태다.
     ```sh
     simai-bootstrap check --sets ppe; echo "exit=$?"
     ```
     `ppe` 묶음(`weights/ppe/T1-v4-ALL-seed20261021-epoch08.pt`)을 받거나 이미지에 구운 사본을 sha256 으로 확인하고 결과 JSON 을 출력한다. 해시 불일치·받기 실패(토큰 권한 없음 401·403 포함)는 `2`, GPU 조건 미달은 `3`(근거: `deploy/README.md` 「simai-bootstrap」, `deploy/scripts/simai_bootstrap.py`).
- **키·위치**: `HF_TOKEN` — RunPod Secret `hf_token`, 이미지 빌드 셸 환경 변수, (AWS 예비) Secrets Manager. 저장소·이미지 층에 남기지 않는다.

## 8. Let's Encrypt (certbot)

- **용도**: `simai.live`, `www.simai.live` TLS 인증서.
- **사용 위치**: `deploy/ec2/compose.yaml` `certbot`, `deploy/web/40-simai-certs.sh`
- **절차**: 01_포팅매뉴얼 5.1-5. 처음은 standalone, 갱신은 webroot 자동.
- **키·위치**: `/opt/simai/.env` → `CERTBOT_EMAIL`
- **특이사항**: 실패 발급은 시간당 5회 제한 → 항상 `--dry-run` 먼저. 무료, 90일 유효.

## 9. 도메인·DNS (호스팅.kr, Cloudflare)

- **용도**: 도메인 `simai.live` 등록(호스팅.kr), DNS 는 Cloudflare Free.
- **설정값**: A 레코드 `@`·`www` → EC2 공인 IP, **Proxy 끔(DNS only)**, TTL Auto. (근거: `docs/design/ec2-deploy.md`)
- **특이사항**: Cloudflare 프록시를 켜면 Let's Encrypt standalone·WebSocket 동작이 달라지므로 끈다.

## 10. SSAFY GitLab ↔ Jenkins

- **용도**: 소스 저장소, MR·push Webhook 으로 Jenkins 빌드, 커밋 상태 회신.
- **사용 위치**: `Jenkinsfile`(`gitLabConnection('gitlab')`), `docs/design/ci-pipeline.md`
- **절차**: GitLab 프로젝트 Settings → Access tokens 에서 `api`(Developer) 토큰과 `read_repository` 토큰 → Jenkins 자격 증명 등록 → GitLab Settings → Webhooks 에 `https://<DOMAIN>/jenkins/project/simai` + Secret token(Push·MR·Comments).
- **키·위치**: Jenkins 자격 증명 저장소(`jenkins-home` 볼륨)에만.
